# Addendum: WASTELAND CHOICE 玩法设计详案

> 本文件是 **BRIEF v0.4** 的配套深度内容（BMAD 约定：细节归 addendum，BRIEF 保持 1–2 页可读）。
> 四大系统（分区探索 / 伙伴招募 / 世界危机等级 / 主角奖励系统）+ 世界观 + 叙事引擎结构在此展开，作为 `bmad-prd` 的直接输入。
>
> **v0.4 修订**：① 区域口径统一为"基地 + 2 可探索"；② 队伍负担恢复真实张力；③ 扩容节奏改为 2 次；④ 新增叙事引擎（剧情主干结构，A16）；⑤ 合并原先重复出现的两处 MVP 表。

## 一、系统一：分区探索

### 1.1 地图状态机
| 状态 | 含义 | 玩家可见信息 |
|---|---|---|
| 🔒 未解锁 | 危机等级不足 | 仅名称轮廓 / 未知 |
| 🌫 已知未探 | 已解锁未进入 | 区域名 + 风险等级 + 传闻收益 |
| 🏠 已探索 | 进入过 | 完整信息 + 可重复进入 + 剩余物资状态 |

### 1.2 探索循环
```
选择目标区域 → 判定消耗(时间/体力/队伍补给)
   → 触发 1~3 个探索事件(物资 / 遭遇 / NPC / 危险)
   → 逐事件决策(战斗/躲藏/交涉/撤退)
   → 结算：带回物资 + 队伍状态变化 + 触发剧情钩子
   → 返回藏身处(或就地扎营/失联)
```

### 1.3 区域属性表（**v0.4 口径统一：MVP 3 区 = 基地 + 2 可探索区**）
| 区域 | 类型 | 风险 | 主要产出 | 特殊机制 | 解锁条件 |
|---|---|---|---|---|---|
| 藏身处（基地） | 基地 | 无 | 建造/休息/分配 | 安全区，队伍在此恢复 | 初始 |
| **超市仓储** | **可探索（首个）** | 中 | 大量食物、工具 | 高价值 → 吸引掠夺者；**NPC 遭遇点（招募主战场）** | 危机 1 级 |
| **医院** | **可探索（第二）** | 高 | 药品、医疗器材、感染线索 | 疫病期价值翻倍；感染者密度高 | 危机 2 级 |

> **MVP 外的扩展区（v0.5+，不纳入本期）**：居民区废墟（低风险、高 NPC 密度）、工业区、荒野加油站、移动堡垒等。

### 1.4 关键设计约束
- 每次探索有**明确机会成本**（体力/时间有限，一天只能选有限区域）。
- **行囊约束的双层结构（v0.4 澄清）**：
  - **物理行囊**：仍有上限，逼迫取舍（拿食物还是药品）。
  - **空间戒指**：突破携带上限，但容量受限且靠成长解锁——是"渐进释放的例外"，不是"无限制豁免"。
- **不死循环**：若资源耗尽，须有"绝境翻盘"路径（如冒险去高风险区），避免卡死。

## 二、系统二：伙伴招募与队伍管理

### 2.1 伙伴数据模型
| 字段 | 说明 |
|---|---|
| 专长 | 战斗 / 医疗 / 工程 / 交涉 / 采集（1–2 项） |
| 数值 | 体力、sanity、忠诚度（0–100） |
| 消耗 | 每日食物/药品消耗（随专长与状态浮动） |
| 诉求 | 个人目标（如"找回妹妹""要药品"）；未满足 → 忠诚度下降 → 可能离队/反水 |
| 剧情线 | 专属支线，随忠诚度/危机推进解锁 |

### 2.2 招募决策矩阵
| NPC 情境 | 选项 | 代价/收益 |
|---|---|---|
| 受伤求助者 | 施救 | -药品，+潜在伙伴（若存活） |
| | 无视 | 0 消耗，-1 sanity（道德负担） |
| 敌对掠夺者 | 战斗 | 高风险，击败可夺物资/俘虏招募 |
| | 谈判 | 交涉专长加成，可能以物资换和平 |
| 交易商人 | 交换 | 物资置换，可能带来稀有物件 |

### 2.3 队伍负担机制（**A10 v0.4 定案：保留真实张力**）
- **定案**：人数 ↑ → **每日消耗显著 ↑** → 真实制造"多一个帮手 or 多一张嘴"的抉择。
- **空间戒指的定位（关键修正）**：
  - ✅ 戒指提供**延迟缓冲**——可预存物资，应对短期饥荒、平抑波动（把"这顿没得吃"变成"还能撑两天，但后天必须出去"）。
  - ❌ 戒指**不消除**队伍规模带来的**长期人均消耗增长**。人数多了，长期口粮缺口依然变大。
- ✂️ **已否决的写法（v0.3 错误）**：原先"轻度负担 + 戒指部分对冲"两条同向削弱叠用，结果是**招募几乎零代价**——核心张力被自己的平衡机制抵消掉。v0.4 明确：**两者不得叠加削弱**。
- **调平提示（转 PRD）**：负担强度的初值需在内测调平，但**方向上必须"真实存在"**，不能靠调低到接近零来回避平衡工作。

### 2.4 忠诚度与流失
- 忠诚度受：诉求满足度、sanity 事件、食物短缺、决策倾向（冷酷/仁慈）影响。
- 流失方式：抱怨 → 拒绝执行 → 离队（带走私人物资）→ 反水（极端）。
- **戏剧性**：忠诚度系统是"决策有代价"在伙伴线上的体现。

## 三、系统三：世界危机等级

### 3.1 危机轴与规则改变
| 等级 | 主题 | 环境规则改变 | 解锁区域 | 主线推进 |
|---|---|---|---|---|
| 1 | 极寒 | 体温下降加快；需保暖/生火 | **超市仓储**（首个探索区） | 第 1 章：找到可靠藏身处 |
| 2 | 疫病 | 新增"感染"数值；药品稀缺 | **医院** | 第 2 章：找到病源/疫苗线索 |
| 3 | 变异兽潮 | 战斗强度激增；夜间危险 | 工业区/荒野（MVP 外） | 第 3 章：抵御兽潮 |
| 4 | 秩序重建 | 从求生转向重建（潜在结局钩子） | — | 终局/多结局 |

> **v0.4 对齐说明**：等级 1/2 解锁的区域即 MVP 的两个可探索区，与 A7（首个探索区 = 超市仓储）一致。

### 3.2 升级触发机制
- **自动推进**：存活天数达阈值。
- **剧情推进**：完成关键节点（如修好电台、找到疫苗）。
- **玩家影响**：部分升级可**延后**（延迟成本 = 储备不足时更凶），制造"要不要苟"的策略。

### 3.3 与其他系统的耦合
```
危机等级 ──► 解锁新区域（系统一）
         ──► 改变环境规则（数值系统）
         ──► 推进主线章节（叙事引擎）
         ──► 触发奖励强化窗口（系统四）
         ◄── 玩家行动可部分影响升级时机
伙伴招募 ──► 影响探索成功率与战斗结果（系统一）
         ──► 消耗资源（数值系统）
区域探索 ──► 产出资源养活队伍（系统二）
         ──► 触发剧情钩子推动危机（系统三）
```

## 四、系统四：主角奖励系统

### 4.1 系统定位
- **系统流金手指**：仅主角持有，NPC 无。属网文"系统文"经典设定，提供爽感与目标感。
- **叙事身份**：奖励系统本身是主线悬念（为何选中主角？系统从何而来？），构成长期追更钩子。`[ASSUMPTION] A15 — MVP 内仅埋钩子、不揭晓`

### 4.2 触发与奖励矩阵
| 触发类型 | 示例 | 奖励类型 | 强度 |
|---|---|---|---|
| 首次抵达区域 | 首次进入医院 | 信息（地图/线索） | 低 |
| 完成生存任务 | 存活满 N 天、队伍不散 | 物资 | 低-中 |
| 关键剧情节点 | 修好电台、找到疫苗线索 | 能力 / 空间扩容 | 中-高 |
| 逆境达成 | 绝境翻盘、零伤亡撤离 | 能力（特殊） | 高 |

### 4.3 奖励四类（与 BRIEF 一致）
1. **物资**：食物/药品/工具——缓解生存压力。
2. **能力**：夜间视野、危险感知、魔法亲和、体魄强化——提升生存与探索半径。
3. **空间扩容**：提升戒指容量/解锁随身空间——成长核心。
4. **信息**：地图情报、剧情线索、稀有 NPC 位置——推动探索与招募。

### 4.4 扩容节奏（**A14 v0.4 定案：MVP 内 2 次**）
| 次序 | 时机 | 效果 | 设计意图 |
|---|---|---|---|
| 初获 | 开局/第 1 章节点 | 获得戒指，基础容量 | 建立"外挂感"起点 |
| 第 1 次扩容 | 危机 1→2 之间 | 容量提升 | 让玩家**真实体验到成长**（而非只被告知会有成长） |
| 第 2 次扩容 | 危机 1→2 升级节点 | 容量再提升 / 解锁功能区 | **双轨对冲**：世界变难的同时主角变强 |

> **为什么必须 2 次**：v0.3 原稿只给"基础容量 + 1 次扩容"——变成只有**一个成长节点**，玩家还没形成"我在变强"的节奏感，MVP 就结束了，导致 A14 的核心假设（成长爽感）**在 MVP 内验证不了**。2 次是能形成"节奏感"的最小值。

### 4.5 平衡纪律（红区）
- **不做自动通关**：奖励是"雪中送炭"，非"直接胜利"。任何奖励不得跳过硬约束（如资源耗尽仍会死）。
- **双轨对冲**：世界危机升级 → 奖励强度同步提升，保持"我在变强，世界更难"的动态平衡。
- **可预期但不无聊**：奖励规则透明（玩家可规划），但内容有随机性（避免公式化）。

## 五、世界观设定详案

### 5.1 世界性质
- **非现实世界**：科技残骸 + 魔法/异能共存的末日废土。
- **灾变成因（暂定）**：空间裂缝/魔法灾难导致文明崩塌——为"世界为何末日"提供世界观级解释，也为后续扩展留口。`[ASSUMPTION] A15`

### 5.2 魔法/异能的设定边界（防设定打架）
| 设定项 | 规则 | 对玩法的影响 |
|---|---|---|
| 异能者/法师 | NPC 与主角均可有；技能非主角独有 | 伙伴专长可含"异能"；探索遭遇可含魔法危机 |
| 魔法装置 | 遗迹/废墟中可拾取 | 新增一类高价值探索产出 |
| 空间戒指 | **主角独有（金手指）** | 核心机制，见 5.3 |
| 魔法与数值 | 所有魔法效果须落到既有数值层（体力/sanity/资源） | 规则层统一校验，禁止"魔法无视数值" |

**设计纪律**：任何魔法设定，都必须能翻译成"对既有数值层的确定性改动"，否则不进设定——这是防止世界观与规则层打架的硬约束。

### 5.3 空间戒指设计
| 属性 | 规则 |
|---|---|
| 基础容量 | 有限（如 16 格），开局非无双 |
| 扩容途径 | **仅通过主角奖励系统解锁**（见第四节），MVP 内 2 次 |
| 随身空间（可选） | 中期解锁：可种植/养殖，提供稳定产出 |
| 平衡约束 | 容量增长须与危机等级同步——世界越难，戒指才越大，否则难度塌陷 |

**关键权衡（红区预警）**：空间戒指解决了"行囊上限"的憋屈感，但也可能**削弱末日紧张感**。平衡方案：
- 戒指**只解决"携带"**，不解决"安全"——藏身仍受威胁；
- 戒指内物资若**全灭**（主角团灭）应真正损失，保留赌注；
- 扩容节奏受危机等级与奖励系统双重约束（MVP 内 2 次），不自由膨胀。

## 六、叙事引擎：剧情主干结构（v0.4 新增 · A16）

> 补齐 v0.3 的架构级空白：**主线剧情由谁生成**。

### 6.1 分工原则
| 层级 | 由谁负责 | 原因 |
|---|---|---|
| **主线骨架**（章节节点、关键决策、结局分支） | **人工大纲** | 保证叙事质量下限与终局可控，避免 LLM 把故事写崩 |
| **场景文本**（环境描写、NPC 对话、事件叙述） | **LLM 填充** | 发挥 LLM 的文本生成优势，降低文案工作量 |
| **数值落点**（每个选项造成的属性变化） | **规则层确定性判定** | 严禁 LLM 自行决定数值，防幻觉破坏平衡 |
| **探索事件**（1~3 个/次探索） | LLM 生成 + 规则层校验 | 探索需大量内容，纯人工不现实；规则层兜住数值 |

### 6.2 主线章节结构（每章统一模板）
```
章节进入条件（危机等级 / 前置节点）
  → 场景铺陈（LLM 生成文本）
  → 关键决策点 1~N（人工定义选项 + 数值后果）
  → 章节结果结算（规则层）
  → 触发奖励 / 解锁区域 / 推进危机等级
```
MVP 内 2 章（对应危机 1→2），每章含 ≥2 个关键决策点。

### 6.3 探索事件结构
```
事件类型（人工定义池：物资 / 遭遇 / NPC / 危险）
  → LLM 按模板生成具体情境文本
  → 规则层注入该事件允许的数值区间
  → 玩家选择 → 规则层结算
```

### 6.4 为什么不用纯 LLM 生成主线
- **质量**：LLM 长程叙事易丢失目标、人物崩坏、结局不可控；
- **纪律冲突**：与"规则层兜底幻觉"的产品纪律相冲突；
- **可复用性**：人工大纲 + AI 填充的**结构本身**可直接成为中期 UGC 剧情编辑器的骨架（见 BRIEF Vision）。

## 七、四系统耦合闭环

```
奖励系统 ──► 空间扩容 → 强化"分区探索"的携带/收益
         ──► 能力奖励 → 提升探索/招募成功率
         ──► 物资奖励 → 缓解"伙伴招募"的短期队伍负担（延迟缓冲，非消除）

世界危机 ──► 解锁新区域（探索）
         ──► 提升难度 → 触发更强奖励（奖励系统）
         ──► 推进主线（叙事）

分区探索 ──► 产出物资养队伍（招募）
         ──► 触发剧情节点（危机 + 奖励）

伙伴招募 ──► 战力/专长反哺探索
         ──► 长期消耗资源（负担真实存在，戒指仅平抑短期波动）
```

**闭环意义**：四个系统共用同一个数值层，互为因果——玩家任一动线都会牵动其余三条，这是"生存 + 成长"双引擎的具体落地。

## 八、MVP 最小可验证集（**v0.4 统一口径**）

| 项 | MVP 值 | 理由 |
|---|---|---|
| 区域总数 | **3 = 藏身处（基地）+ 2 个可探索区（超市仓储 / 医院）** | 够跑通"探索→产出→再探索"循环 |
| 可招募伙伴 | 2 | 够验证"招募负担 + 忠诚度" |
| 危机等级 | 2（极寒 → 疫病） | 够验证"升级→解锁→新规则" |
| 奖励发放 | ≥4 次（覆盖四类奖励） | 够验证"金手指成长感" |
| 空间戒指 | 基础容量 + **2 次扩容** | 够形成"成长节奏感"，而非单点 |
| 关键决策点 | ≥5 | 覆盖探索/招募/危机三类 |
| 主线章节 | 2 章（每章 ≥2 关键决策点） | 够验证"人工大纲 + LLM 填充"链路 |
| 结局 | ≥2 | 验证多结局与复盘 |

**验证目标**：玩家是否真的感到"我在一个异世界末日里靠金手指活下去、并把队伍带大"，而非"我在读一个分支小说"。

## 九、待深化（转 PRD 阶段的输入）
- 数值平衡表（各资源产出/消耗速率、难度曲线、**队伍人均消耗曲线**）
- 探索事件的 LLM prompt 模板 + 规则层校验用例
- 主线章节大纲（2 章的节点图与结局分支）
- 危机升级的具体阈值与可影响窗口
- 伙伴忠诚度的状态机与触发事件表
- 存档/分支图的 UI 与数据结构
- 评审状态：**A1~A18 全部闭环**（A17 sanity 弱化惩罚 / A18 MVP 不做插画）
