# Addendum: WASTELAND CHOICE 玩法设计详案

> 本文件是 **BRIEF v0.5** 的配套深度内容（BMAD 约定：细节归 addendum，BRIEF 保持可读）。
> **五大系统**（基地建设 / 搜打撤出击 / 伙伴招募 / 世界危机等级 / 主角奖励系统）+ 世界观 + 叙事引擎结构在此展开，作为 `bmad-prd` 的直接输入。
>
> **v0.5 修订**：① 新增「系统一：基地建设」（4 项设施 · 2 级）；② 系统二由"分区探索"改写为**搜打撤循环**（撤离点 / 容器二分 / 失败分级）；③ 伙伴改为**双层制**；④ 危机等级绑定**天数区间**（14 天封顶）；⑤ 空间戒指重新定位为**安全格**；⑥ 四系统耦合升级为**五系统耦合**。
> 旧版见 `_archive-addendum-v0.4.md` / `_archive-addendum-v0.3.md`。

## 零、核心循环总览

```
        ┌────────────────── 世界危机等级（时间驱动 · 14 天封顶）──────────────────┐
        │   等级 1（第 1–7 天）→ 等级 2（第 8–14 天）                            │
        │   升级效果：解锁新区域 · 改变环境规则 · 强化奖励强度                     │
        └───────────────────────────────┬───────────────────────────────────────┘
                                        ▼
   ┌─▶ 基地 ──▶ 出击（搜打撤）──▶ 结算 ─┐
   │ （整备/建造/恢复）  （进入→搜刮→撤离） （入账/损失/消耗）
   │      ▲                              │
   │      └── 资源投入建设 → 能力提升 ◀───┘
   └──────────────────────────────────────┘
```

**循环闭合的三条硬约束：**

| # | 约束 | 若违反的后果 |
|---|---|---|
| 1 | 撤离失败必须有可感知损失 | 最优解退化为"搜无可搜再走"，搜打撤机制失效 |
| 2 | 每项设施必须落成可测数值修正 | 基地沦为装饰，经营感不成立 |
| 3 | 基地已建设施不受出击失败影响 | 失败 = 推倒重来，挫败感超过可承受阈值 |

## 一、系统一：基地建设

### 1.1 定位
基地是**唯一的固定据点**，承担三个职能：**恢复锚点**（体力/体温/sanity 恢复）、**资源消耗端**（把出击产出转化掉）、**能力提升器**（设施提供持久数值增益）。

### 1.2 设施表（MVP 锁定 4 项 · 2 级）

| 设施 | 作用线 | 1 级效果 | 2 级效果 | 升级成本（示意） |
|---|---|---|---|---|
| **床铺** | 恢复 | 每日体力恢复 +1 | 重伤状态恢复速度 +100% | 布料 ×2 → 布料 ×4 + 工具 ×1 |
| **火堆** | 保暖 | 基地内体温衰减 -30% | 提供"范围保暖"，极寒期外出体温衰减 -15% | 木材 ×3 → 木材 ×6 + 燃料 ×2 |
| **净水** | 资源 | 每日净水产出 +1 | 产出 +2，且队伍饮水消耗 -20% | 容器 ×2 → 容器 ×3 + 工具 ×1 |
| **储物** | 容量 | 基地存储上限 +20 | **行囊容量 +1**（出击携带上限） | 板材 ×3 → 板材 ×6 + 工具 ×2 |

> **设计意图**：四项设施分别对应恢复、保暖、资源、容量四条成长线，**任意一项都不与空间戒指（安全格）功能重叠**——储物线提高的是**风险格**容量，而不是安全格。

### 1.3 升级机制
- 消耗出击带回的**特定资源**（工具/材料类，非食物），成本随等级递增。
- 建造**即时生效**，无建造排队（MVP 简化）。
- 每项设施独立升级，不设基地总等级。

### 1.4 设计边界（明确不做）
- ❌ 复杂生产链（A 产出 → B 加工 → C 成品）
- ❌ 设施空间布局 / 房间规划
- ❌ 多基地 / 基地选址
- ❌ 设施耐久度与损毁（基地是安全资产，不受破坏）

## 二、系统二：搜打撤出击

### 2.1 地图状态机
| 状态 | 含义 | 玩家可见信息 |
|---|---|---|
| 🔒 未解锁 | 危机等级不足 | 仅名称轮廓 / 未知 |
| 🌫 已知未探 | 已解锁未进入 | 区域名 + 风险等级 + 传闻收益 |
| 🏠 已探索 | 进入过 | 完整信息 + 可重复进入 + 剩余物资状态 |

### 2.2 搜打撤循环（v0.5 核心改写）

```
出击（消耗体力进入）
  → 搜刮：逐次消耗体力，累积战利品
      · 累积收益：边际递减（好东西先被搜走）
      · 暴露风险：加速上升（时间越久，遭遇/环境伤害概率越高）
  → 每轮搜刮后给玩家一次决策：
      A. 继续深入（收益↑，风险↑↑）
      B. 前往撤离点（锁定当前收益）
  → 撤离判定：
      成功 → 战利品入账
      失败 → 见 2.4 失败分级
```

**张力来源**：收益线与风险线的交叉点即"该撤了"的心理位置（见 BRIEF 核心玩法主线图）。玩家的每一次"再搜一个"都是在赌。

### 2.3 容器二分（v0.5 关键机制）

| 容器 | 容量 | 失败时 | 定位 |
|---|---|---|---|
| **物理行囊** | 大（初始 6，可被"储物"设施 +1） | ❌ **全部损失** | 风险格 |
| **空间戒指** | **小（初始 2 格，扩容后 4 → 6）** | ✅ 保底 | 安全格 |

**机制说明：**
- 每次获得战利品后，玩家可**显式指定**放入哪个容器；戒指满则只能进行囊。
- **核心决策**："哪几件最值得占用安全格？"——这构成每轮出击的新决策层。
- **扩容的语义**：奖励系统发放空间扩容 = **安全格变大**，是"金手指成长"最直观的体现。

**⚠️ 已否决的写法（v0.5 明确否决）：**
- ❌ **戒指大容量 / 无条件保底** —— 会导致失败零代价（搜到就存 → 行囊永远空 → 撤离决策失去动机 → 退化为扫荡模式）。
- ❌ **戒指容量等于或大于行囊** —— 二分结构失效，等同于无风险格。

> 参照设计：《逃离塔科夫》的安全容器（Gamma 3×3）——保底存在，但装不下大头。

### 2.4 失败分级（v0.5 定案）

| 层级 | 触发条件 | 后果 | 是否触发终局 |
|---|---|---|---|
| **撤离受挫** | 被拦截 / 撤离点关闭 / 超时 | 丢部分战利品（行囊内随机一半），可脱身 | ❌ |
| **失联** | 体力归零 / 被击倒 | **行囊全丢（戒指内保底）** + **本次可招募 NPC 机会错过**（位置留下可见痕迹）+ 主角重伤 | ❌ |
| **团灭** | 体温归零 / 饥饿归零 | 本局结束，进入复盘 | ✅ |

> **为什么单次失败不触发结局**：一局为 14 天，若每次出击失败都结束游戏，主线章节（2 章）没有展开空间。失败惩罚落在"损失 + 时间成本"上，而非"推倒重来"。

### 2.5 招募惩罚的可感知性要求

"错过本次可招募 NPC"这一惩罚存在**天然的可感知性缺陷**——玩家不知道"如果没失败本来会遇到谁"。

**必要条件**：失败后，该 NPC 位置须留下**可见痕迹**，至少满足一条：
- 废弃营地 / 熄灭的篝火 / 遗留的私人物品
- 中断的呼救信号（收音机截断音）
- 血迹或拖拽痕迹

若错过的是**叙事核心伙伴**，则代价升级为**永久丧失该角色的专属剧情线**（代价显著，需谨慎设计触发时机）。

### 2.6 区域属性表（MVP 3 区 = 基地 + 2 可探索区）

| 区域 | 类型 | 风险 | 主要产出 | 特殊机制 | 解锁条件 | 撤离点 |
|---|---|---|---|---|---|---|
| 基地 | 基地 | 无 | 建造/休息/分配 | 安全区，设施在此建造 | 初始 | — |
| **超市仓储** | **可探索（首个）** | 中 | 大量食物、工具、材料 | 高价值 → 吸引掠夺者；**随机路人遭遇点** | 危机 1 级 | 2 个（入口 / 后巷） |
| **医院** | **可探索（第二）** | 高 | 药品、医疗器材、感染线索 | 疫病期价值翻倍；感染者密度高 | 危机 2 级 | 2 个（正门 / 消防梯） |

> **MVP 外的扩展区（v0.6+，不纳入本期）**：居民区废墟（低风险、高 NPC 密度）、工业区、荒野加油站、移动堡垒等。
> **扩结构不扩内容**：区域由配置表驱动，扩展区仅需追加配置，无需代码改动。

### 2.7 关键设计约束
- 每次出击有**明确机会成本**（体力有限，一天内能出击的次数受限）。
- **不死循环**：若资源耗尽，须有"绝境翻盘"路径（如冒险去高风险区），避免卡死。
- **撤离点可见性**：撤离点位置对玩家**部分可见**（已知大致方位，但需实际抵达确认），避免"看不见出口"的挫败感。

## 三、系统三：伙伴招募与队伍管理

### 3.1 双层结构（v0.5 定案）

| 类型 | 产生方式 | 特征 | 数量（MVP） |
|---|---|---|---|
| **叙事核心伙伴** | 固定，剧情节点解锁 | 有名有姓、背景故事、专属剧情线；**不会随机消失** | 2 名 |
| **随机路人** | 出击中随机遭遇 | LLM 生成姓名/专长/诉求；数值向；**可失去** | N 名（池化生成） |

**为什么必须分层**：随机生成的 NPC 无法承载"专属剧情线"，二者逻辑互斥。分层后"随机触发招募"与"角色立体"两个需求同时成立。

### 3.2 伙伴数据模型
| 字段 | 说明 |
|---|---|
| 类型 | 叙事核心 / 随机路人 |
| 专长 | 战斗 / 医疗 / 工程 / 交涉 / 采集（1–2 项） |
| 数值 | 体力、sanity、忠诚度（0–100） |
| 消耗 | 每日食物/药品消耗（随专长与状态浮动） |
| 诉求 | 个人目标（如"找回妹妹""要药品"）；未满足 → 忠诚度下降 → 可能离队/反水 |
| 剧情线 | 仅叙事核心伙伴拥有；随机路人**无专属支线** |

### 3.3 招募决策矩阵
| NPC 情境 | 选项 | 代价/收益 |
|---|---|---|
| 受伤求助者 | 施救 | -药品，+潜在伙伴（若存活） |
| | 无视 | 0 消耗，-1 sanity（道德负担） |
| 敌对掠夺者 | 战斗 | 高风险，击败可夺物资/俘虏招募 |
| | 谈判 | 交涉专长加成，可能以物资换和平 |
| 交易商人 | 交换 | 物资置换，可能带来稀有物件 |

### 3.4 队伍负担机制（A10 定案：保留真实张力）
- **定案**：人数 ↑ → **每日消耗显著 ↑** → 真实制造"多一个帮手 or 多一张嘴"的抉择。
- **空间戒指的定位**：
  - ✅ 戒指提供**延迟缓冲**——预存物资应对短期饥荒、平抑波动。
  - ❌ 戒指**不消除**队伍规模带来的**长期人均消耗增长**。
- ✂️ **已否决的写法（v0.3 错误）**："轻度负担 + 戒指部分对冲"两条同向削弱叠用 → 招募几乎零代价。**两者不得叠加削弱。**

### 3.5 忠诚度与流失
- 忠诚度受：诉求满足度、sanity 事件、食物短缺、决策倾向（冷酷/仁慈）、**出击失败频率**影响。
- 流失方式：抱怨 → 拒绝执行 → 离队（带走私人物品）→ 反水（极端）。
- **戏剧性**：忠诚度系统是"决策有代价"在伙伴线上的体现。

## 四、系统四：世界危机等级

### 4.1 危机轴 × 天数映射（v0.5）

| 等级 | 主题 | **天数区间** | 环境规则改变 | 解锁区域 | 主线推进 |
|---|---|---|---|---|---|
| 1 | 极寒 | **第 1–7 天** | 体温下降加快；需保暖/生火 | **超市仓储** | 第 1 章：找到可靠藏身处 |
| 2 | 疫病 | **第 8–14 天** | 新增"感染"数值；药品稀缺 | **医院** | 第 2 章：找到病源/疫苗线索 |
| 3 | 变异兽潮 | （MVP 外） | 战斗强度激增；夜间危险 | 工业区/荒野（MVP 外） | 第 3 章：抵御兽潮 |
| 4 | 秩序重建 | （MVP 外） | 从求生转向重建 | — | 终局/多结局 |

`[ASSUMPTION] A26` 天数为初值，内测标定。**终局 = 存活满第 14 天结算，或体温/饥饿归零团灭。**

### 4.2 升级触发机制
- **主触发**：**存活天数达阈值**（唯一主轴，避免多触发并存导致节奏失控）。
- **可提前**：完成关键剧情节点（如修好电台、找到疫苗线索）可提前升级。
- **可延后**：部分升级可**延后**（延迟成本 = 储备不足时更凶），制造"要不要苟"的策略。

### 4.3 与其他系统的耦合
```
危机等级 ──► 解锁新区域（系统二）
         ──► 改变环境规则（数值系统）
         ──► 推进主线章节（叙事引擎）
         ──► 触发奖励强化窗口（系统五）
         ◄── 玩家行动可部分影响升级时机

基地建设 ──► 提升恢复/保暖/资源/容量（系统一）
         ◄── 消耗出击带回的资源

伙伴招募 ──► 影响出击成功率与战斗结果（系统二）
         ──► 消耗资源（数值系统）
         ◄── 出击失败可能动摇忠诚度

区域探索 ──► 产出资源养活队伍（系统三）
         ──► 产出资源支撑基地建设（系统一）
         ──► 触发剧情钩子推动危机（系统四）
```

## 五、系统五：主角奖励系统

### 5.1 系统定位
- **系统流金手指**：仅主角持有，NPC 无。属网文"系统文"经典设定，提供爽感与目标感。
- **叙事身份**：奖励系统本身是主线悬念（为何选中主角？系统从何而来？），构成长期追更钩子。`[ASSUMPTION] A15 — MVP 内仅埋钩子、不揭晓`

### 5.2 触发与奖励矩阵
| 触发类型 | 示例 | 奖励类型 | 强度 |
|---|---|---|---|
| 首次抵达区域 | 首次进入医院 | 信息（地图/线索） | 低 |
| 完成生存任务 | 存活满 N 天、队伍不散 | 物资 | 低-中 |
| 关键剧情节点 | 修好电台、找到疫苗线索 | 能力 / 空间扩容 | 中-高 |
| **逆境达成** | **零战利品损失撤离 / 单次出击满载撤离** | 能力（特殊） | 高 |

> **v0.5 新增触发「逆境达成」**：与搜打撤机制直接挂钩，奖励"在风险边缘成功收手"的行为，正向强化撤离决策。

### 5.3 奖励四类
1. **物资**：食物/药品/工具——缓解生存压力。
2. **能力**：夜间视野、危险感知、魔法亲和、体魄强化——提升生存与出击半径。
3. **空间扩容**：**提升戒指（安全格）容量**——成长核心。
4. **信息**：地图情报、剧情线索、**撤离点位置**、稀有 NPC 位置。

### 5.4 扩容节奏（A14 定案：MVP 内 2 次）
| 次序 | 时机 | 效果 | 设计意图 |
|---|---|---|---|
| 初获 | 开局/第 1 章节点 | 获得戒指，**安全格 2 格** | 建立"外挂感"起点 |
| 第 1 次扩容 | 危机 1→2 之间 | 安全格 2 → 4 | 让玩家**真实体验到成长** |
| 第 2 次扩容 | 危机 1→2 升级节点 | 安全格 4 → 6 | **双轨对冲**：世界变难的同时主角变强 |

> **为什么必须 2 次**：只给 1 次扩容 → 只有一个成长节点 → 玩家尚未形成"我在变强"的节奏感。2 次是能形成"节奏感"的最小值。
> **为什么扩容必须绑危机等级**：世界越难，安全格才越大；否则难度塌陷（保底能力远超风险强度）。

### 5.5 平衡纪律（红区）
- **不做自动通关**：奖励是"雪中送炭"，非"直接胜利"。
- **双轨对冲**：世界危机升级 → 奖励强度同步提升。
- **可预期但不无聊**：奖励规则透明（玩家可规划），内容有随机性。

## 六、世界观设定详案

### 6.1 世界性质
- **非现实世界**：科技残骸 + 魔法/异能共存的末日废土。
- **灾变成因（暂定）**：空间裂缝/魔法灾难导致文明崩塌。`[ASSUMPTION] A15`

### 6.2 魔法/异能的设定边界（防设定打架）
| 设定项 | 规则 | 对玩法的影响 |
|---|---|---|
| 异能者/法师 | NPC 与主角均可有；技能非主角独有 | 伙伴专长可含"异能"；出击遭遇可含魔法危机 |
| 魔法装置 | 遗迹/废墟中可拾取 | 新增一类高价值探索产出 |
| 空间戒指 | **主角独有（金手指）** | 核心机制，见 6.3 |
| 魔法与数值 | 所有魔法效果须落到既有数值层（体力/sanity/资源） | 规则层统一校验，禁止"魔法无视数值" |

**设计纪律**：任何魔法设定都必须能翻译成"对既有数值层的确定性改动"，否则不进设定。

### 6.3 空间戒指设计（v0.5 重新定位）
| 属性 | 规则 |
|---|---|
| **定位** | **安全格**——失败时保底，但容量小 |
| 基础容量 | **2 格**（远小于行囊初始 6） |
| 扩容途径 | **仅通过主角奖励系统解锁**，MVP 内 2 次（2 → 4 → 6） |
| 容量上限约束 | **不得超过行囊容量**——否则风险格失去意义 |
| 随身空间（可选） | 中期解锁：可种植/养殖，提供稳定产出（MVP 关闭） |

**关键权衡（红区预警）**：戒指同时具备"金手指优势"与"张力杀手"两重性。平衡方案：
- 戒指**只降低损失上限**，不**消除**风险——行囊内的大头始终暴露；
- 戒指容量增长**必须绑危机等级**；
- 刻意保留"戒指装不下"的常态，让玩家持续面对取舍。

## 七、叙事引擎：剧情主干结构

### 7.1 分工原则
| 层级 | 由谁负责 | 原因 |
|---|---|---|
| **主线骨架**（章节节点、关键决策、结局分支） | **人工大纲** | 保证叙事质量下限与终局可控 |
| **场景文本**（环境描写、NPC 对话、事件叙述） | **LLM 填充** | 发挥 LLM 文本生成优势 |
| **数值落点**（每个选项造成的属性变化） | **规则层确定性判定** | 严禁 LLM 自行决定数值 |
| **探索事件**（出击中的物质/遭遇/危险） | LLM 生成 + 规则层校验 | 出击需大量内容，纯人工不现实 |

### 7.2 主线章节结构（每章统一模板）
```
章节进入条件（危机等级 / 前置节点）
  → 场景铺陈（LLM 生成文本）
  → 关键决策点 1~N（人工定义选项 + 数值后果）
  → 章节结果结算（规则层）
  → 触发奖励 / 解锁区域 / 推进危机等级
```
MVP 内 2 章（对应危机 1→2），每章含 ≥2 个关键决策点。

### 7.3 出击事件结构（v0.5 更新）
```
事件类型（人工定义池：物资 / 遭遇 / 危险 / 伙伴）
  → LLM 按模板生成具体情境文本
  → 规则层注入该事件允许的数值区间
  → 玩家选择 → 规则层结算
  → 影响后续的风险累积曲线（v0.5 新增：事件可改变风险斜率）
```

### 7.4 为什么不用纯 LLM 生成主线
- **质量**：LLM 长程叙事易丢失目标、人物崩坏、结局不可控；
- **纪律冲突**：与"规则层兜底幻觉"的产品纪律相冲突；
- **可复用性**：人工大纲 + AI 填充的**结构本身**可直接成为中期 UGC 剧情编辑器的骨架。

## 八、五系统耦合闭环（v0.5 升级）

```
基地建设 ──► 提升恢复/保暖/资源/行囊容量
         ◄── 消耗出击带回的特定资源

搜打撤出击 ──► 产出资源（行囊风险格 / 戒指安全格）
           ──► 累积风险 → 撤离决策
           ◄── 失败损失行囊、错过招募机会

奖励系统 ──► 安全格扩容 → 提升保底能力
         ──► 能力奖励 → 提升出击/招募成功率
         ──► 物资奖励 → 缓解队伍短期负担（延迟缓冲，非消除）

世界危机 ──► 解锁新区域 · 提升难度 · 触发更强奖励 · 推进主线
         ◄── 天数驱动，玩家可部分影响时机

伙伴招募 ──► 战力/专长反哺出击
         ──► 长期消耗资源（负担真实存在）
         ◄── 出击失败动摇忠诚度
```

**闭环意义**：五个系统共用同一个数值层，互为因果——玩家任一动线都会牵动其余四条。这是"经营 + 撤离 + 成长"三引擎的具体落地。

## 九、MVP 最小可验证集（v0.5 统一口径）

| 项 | MVP 值 | 理由 |
|---|---|---|
| 区域总数 | **3 = 基地 + 2 探索区（超市仓储 / 医院）** | 够跑通"出击→产出→建设→再出击"循环 |
| **基地设施** | **4 项（床铺/火堆/净水/储物）· 2 级** | 够验证"经营感"与"资源消耗端" |
| 可招募伙伴 | **2 名叙事核心 + N 名随机路人** | 够验证"双层结构 + 招募负担 + 忠诚度" |
| 危机等级 | 2（极寒 → 疫病） | 够验证"升级→解锁→新规则" |
| **存活天数** | **14 天封顶**（等级 1: 1–7 天 / 等级 2: 8–14 天） | 够容纳 2 章主线 + 多轮出击 |
| **出击次数** | **≥6 次**（不设单次时长） | 够形成"从不敢深入 → 敢满载撤离"的成长曲线 |
| 奖励发放 | ≥4 次（覆盖四类，含 2 次安全格扩容） | 够验证"金手指成长感" |
| **空间戒指** | **安全格 2 格起 + 2 次扩容（2→4→6）** | 够形成"成长节奏感"，且始终小于行囊 |
| 关键决策点 | ≥8 | 覆盖出击/撤离/招募/建造四类 |
| 主线章节 | 2 章（每章 ≥2 关键决策点） | 够验证"人工大纲 + LLM 填充"链路 |
| 结局 | ≥2（14 天存活结算 / 团灭） | 验证多结局与复盘 |

**验证目标**：玩家是否真的感到"我在一个异世界末日里靠金手指活下去、把基地建起来、把队伍带大"，而非"我在读一个分支小说"。
