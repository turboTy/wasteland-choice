# Product Brief: 末世求生：抉择（暂定代号 WASTELAND CHOICE）

> 版本 **v0.4-draft** · 由 bmad-product-brief（Fast path）起草 · 缺口以 `[ASSUMPTION]` 标注，待评审确认。
> **v0.4 修订重点（口径统一与决策落定）**：① 统一"3 区域"的三处冲突口径；② A7 首个探索区定案并与危机解锁表对齐；③ A10 伙伴负担恢复真实张力（戒指改为延迟缓冲而非消除代价）；④ A14 扩容节奏改为 MVP 内 2 次；⑤ 新增**剧情主干生成方式**（架构级空白补齐）；⑥ A2 用户画像降级为远期假设、A6 成功信号改为定性。
> v0.3 / v0.2 / v0.1 存档见对应 `_archive-*.md`。

## Executive Summary

一款 **LLM 驱动的异世界末世生存互动沙盒游戏**：玩家扮演一名**携带"奖励系统"金手指的穿越者**，进入一个**存在魔法与空间戒指的末日世界**。玩家在分区地图上探索区域、搜集物资（可存入空间戒指）、招募伙伴、搭建藏身处；随**世界危机等级**逐级升级（极寒 → 疫病 → 变异兽潮 → 秩序重建），环境规则改变、新区域与新剧情解锁。主角的**奖励系统**在达成任务/条件时发放物资、能力与空间扩容，形成"个人成长 vs 世界恶化"的双轨张力。

这踩在两个已验证的风口交汇点：① AI 漫剧供给井喷、末世为最高频题材（来源：[投资界/骨朵数据](https://news.pedaily.cn/202606/564702.shtml)）；② **互动化是明确趋势**——番茄平台《全球冰封》让观众以"幸存者"身份做决策、分支结局（来源：[羊城晚报](https://ep.ycwb.com/epaper/ycwb/resfile/2026-07-12/A05/ycwb20260712A05.pdf)）。本产品在"末世 + 互动"之上再加一层**网文式爽感内核**（金手指 + 空间戒指 + 系统流），差异点在**"探索 → 招募 → 生存代价"闭环 + 主角金手指成长 + 规则层兜底**。

`[ASSUMPTION]` 本产品定位为**个人兴趣试点 + BMAD 方法验证载体**，非公司主业延伸，故 MVP 极致轻、先自用/小范围内测，规避发布型监管。

## 世界观设定（v0.3 新增）

> 关键前提：**这不是现实世界**。世界观是"科技+魔法"混合的末日废土，为玩法提供额外的资源与力量维度。

- **魔法存在**：世界存在异能者/法师/魔法装置；灾变（末日来临）被设定为与魔法/空间裂缝相关，为后续世界观扩展留口。
- **空间戒指（核心机制）**：主角持有的标志性道具，**可收纳远超物理容量的物资装备**，并**可种植/养殖（随身空间）**。它直接改写了"末日生存"的两个核心难题——**携带上限**与**藏身安全**：
  - 解决"行囊上限"（v0.2 的取舍约束）→ 但引入新的平衡问题：戒指容量需**成长解锁**，非开局无双。
  - 提供"随身安全屋"雏形 → 降低团灭风险，但可能削弱紧张感（**需平衡**，见风险黄区）。
- **设定程度**：**强设定 / 核心机制**——空间戒指是主角的核心外挂，直接参与玩法（资源携带、藏身、种植），而非纯背景氛围。`[ASSUMPTION] A12 ✅已确认`

## 主角专属机制：奖励系统（v0.3 新增）

> **系统流金手指**：仅主角持有，其他 NPC 没有。这是爽感与成长的核心引擎。

- **触发方式**：完成任务 / 达成条件 / 首次抵达某区域 / 关键剧情节点 → 发放奖励。
- **奖励类型**：
  1. **物资奖励**（食物、药品、工具——缓解生存压力）
  2. **能力奖励**（如夜间视野、危险感知、魔法亲和、体魄强化）
  3. **空间扩容**（提升空间戒指容量/解锁随身空间功能区）
  4. **信息奖励**（地图情报、剧情线索、稀有 NPC 位置）
- **设计边界**：
  - **不做纯自动胜利**：奖励是"雪中送炭"而非"直接通关"，避免游戏失去张力。
  - **与危机等级对冲**：世界越危险，系统奖励越强，制造"我在变强，但世界也在恶化"的双轨节奏。`[ASSUMPTION] A13 ✅已确认`
  - **叙事合理性**：奖励系统本身是世界观谜团（为何选中主角？），构成主线悬念钩子。`[ASSUMPTION] A15 — MVP 内仅埋钩子，不揭晓（见 A15 定案）`
- **扩容节奏（v0.4 定案）**：MVP 内**给出 2 次空间扩容**（初获 → 成长 → 配合危机等级 1→2 的第二次扩容），确保"成长爽感"这条核心假设**在 MVP 内可被真实体验到**，而非停留在承诺。`[ASSUMPTION] A14 ✅已确认`

## The Problem

- **现有末世 AI 漫剧是"被动消费"**：观众看分支选择，缺乏"我的选择真的会让队伍饿死/团灭"的**数值化代价感**，沉浸浅、replay 价值低。
- **互动叙事游戏（如 AI Dungeon）缺乏"末世生存 + 成长系统"的硬约束框架**：无资源/体力/温度等生存系统，也无清晰的成长反馈，决策后果飘忽。
- **供给饱和下的审美疲劳**：截至 2026-03 在播 AI 漫剧近 18 万部，末世题材 1.8 万部+，纯内容型产品极易被淹没（来源：[投资界](https://news.pedaily.cn/202606/564702.shtml)）。
- **用户（玩家）痛点**：想要"我主导的末日求生 + 我自己的金手指成长"——能探索、能囤货（空间戒指）、能拉人入伙、能靠系统一步步变强，而非"别人写好的爽文"。

## The Solution

以 **LLM（如 DeepSeek / 通义 / 自选 API）+ 规则层（确定性模拟）+ 轻量前端** 构建。**四大系统**：

### 系统一：分区探索（探索区域寻找物资）
- **分区地图（v0.4 口径统一）**：MVP 共 **3 个区域 = 1 个基地（藏身处）+ 2 个可探索区**。三态管理（未解锁 / 已知未探 / 已探索）。
  - **首个探索区定案**：**超市仓储**（与危机等级 1 解锁对齐，见下）。`[ASSUMPTION] A7 ✅已确认`
  - 第二探索区：**医院**（危机等级 2 解锁）。
- **探索循环**：选目标区域 → 消耗时间/体力 → 触发探索事件（物资、遭遇、危险、NPC）→ 带战利品返回或就地决策。
- **风险回报**：越深/越远越好，但遭遇战/辐射/寒潮风险越高——资源-风险权衡。
- **行囊约束的新解法（v0.3）**：物理行囊仍有上限，但**空间戒指可突破**（容量随奖励系统成长）——形成"外挂优势"的渐进释放。
- **区域解锁**：由世界危机等级驱动。

### 系统二：伙伴招募与队伍管理（招募伙伴）
- **招募途径**：探索中遭遇 NPC（求助/敌对/中立），通过决策（给物资/施救/交易）招募。
- **伙伴属性**：专长（战斗/医疗/工程/交涉/采集）+ 独立 sanity/忠诚度 + 个人诉求（未满足可能离队/反水）。
- **队伍负担（v0.4 定案）**：食物/药品消耗随人数**真实增长**——"多一个帮手还是多一张嘴"。`[ASSUMPTION] A10 ✅已确认（保留真实张力）`
  - **空间戒指的定位修正（重要）**：戒指提供的是**延迟缓冲**（可预存物资应对短期饥荒、平抑波动），**不消除**队伍规模带来的**长期人均消耗增长**。
  - ✂️ **已否决的写法**：v0.3 曾写"戒指物资可**部分对冲**队伍负担"，与"轻度负担"叠加后会导致**招募零代价**、核心张力名存实亡。v0.4 明确二者**不叠加削弱**。
- **伙伴叙事**：背景故事与专属剧情线。

### 系统三：世界危机等级（末日模式升级推进剧情）
- **四级危机轴**：`极寒 → 疫病 → 变异兽潮 → 秩序重建`；每升一级：① 环境规则改变；② 解锁新区域；③ 推进主线章节。
- **升级触发**：存活天数 / 关键剧情节点 / 玩家行动（如修好电台）驱动，玩家可部分影响时机。
- **与区域的对应（v0.4 对齐）**：

  | 等级 | 主题 | 解锁区域 |
  |---|---|---|
  | 1 | 极寒 | 超市仓储（首个探索区） |
  | 2 | 疫病 | 医院 |
  | 3 | 变异兽潮 | （MVP 外） |
  | 4 | 秩序重建 | （MVP 外） |

- **v0.3 补充**：危机升级也是**奖励系统的强化窗口**——世界越难，系统奖励越强（双轨对冲）。

### 系统四：主角奖励系统（v0.3 新增 · 系统流金手指）
- **触发**：任务/条件/首次抵达/剧情节点。
- **奖励**：物资 / 能力 / 空间扩容 / 信息（详见上节「主角专属机制」）。
- **定位**：主角独有成长引擎，提供**爽感节奏**与**长期目标感**，同时是世界观悬念的载体。

### 支撑系统（v0.1/v0.2 保留）
- **叙事引擎（v0.4 补齐生成方式）**：
  - **主线章节**：**人工写大纲**（章节节点、关键决策、结局分支由人定）+ **LLM 填充场景文本**。保证叙事质量下限与终局可控。`[ASSUMPTION] A16 — 新增`
  - **探索事件**：LLM 生成 + 规则层校验（数值落点必须确定性）。
  - **设计理由**：纯 LLM 生成主线会导致剧情飘忽、结局不可控，与本产品"规则层兜底幻觉"的设计纪律相冲突；全人工则工程量过大。**大纲人工 + 文本 AI** 是质量与成本的平衡点，且该结构可**直接复用**为后续 UGC 剧情编辑器的模板。
- **生存数值面板**：体温 / 饥饿 / 体力 / 资源 / sanity / 队伍状态，漫剧风 UI。
  - `[ASSUMPTION] A17 — 新增` **sanity 取向**：sanity 与忠诚度挂钩，属偏写实压抑设计，而 v0.4 定位已转向"金手指爽文流"。**建议保留 sanity 但弱化惩罚**（影响局部选项/对话倾向，不直接致死），避免"又爽又丧"的体验冲突。待裁决。
- **决策系统**：关键节点 2–4 选项，绑定数值变化；蝴蝶效应。
- **多结局 + 复盘**：存档、分支图、结局归因。
- **画面策略（后置）**：MVP 纯文字+面板；后续**关键帧预生成插画**补漫剧质感，绝不实时生成视频。
  - `[ASSUMPTION] A18 — 新增` 插画与"不做内容军备竞赛"的关系需明确：**MVP 不做插画**，插画仅为 MVP 验证通过后的**可选加分项**，不作为差异化壁垒。

## What Makes This Different

- **"末世生存 + 异世界魔法 + 系统流金手指"三层叠加**：市面竞品要么纯写实生存、要么纯爽文系统流；本产品用**同一套数值系统**把"生存压力"与"成长爽感"焊在一起。
- **空间戒指改写生存公式**：它既是"外挂优势"（突破携带上限）又是"新的平衡难题"（容量成长、是否削弱紧张感）——**不送无双**，靠成长解锁。
- **决策有真实代价**：开门/拒绝、施救/抛弃、招募/独行，都真的改动资源与队伍状态，甚至团灭——**主体责任感**。
- **规则层兜底 LLM 幻觉**：确定性数值/状态机约束 LLM，保证剧情连贯、数值平衡（竞品纯 LLM 易崩）。
- **不做内容军备竞赛**：拼**玩法深度 + 成长节奏 + replay 价值**。
- 诚实声明：若壁垒仅是"文案 + 套壳 LLM"，则**无技术护城河**；护城河在**数值平衡 + 系统设计（探索/招募/危机/奖励）+ 剧情分支质量**。`[ASSUMPTION]`

## Who This Serves

- **核心用户（远期假设，MVP 阶段不作为验收项）**：18–35 岁男性为主，网文（系统流/末世流/随身空间流）、短剧、生存游戏（《明日之后》《饥荒》《归家异途》《这是我的战争》）玩家，C 端，追求"主导感 + 经营感 + 成长爽感"。`[ASSUMPTION] A2 — ⬇️已降级为远期假设`
  - **降级理由（v0.4）**：A3 已定"先自用/demo、不发布"，MVP 阶段的唯一用户是开发者本人。此时固化 C 端画像**无处落地**、也不该占用 MVP 验收资源。待进入"是否发布"决策时再启用。
- **次要用户**：互动叙事爱好者、AI 内容创作者（潜在 UGC 剧情作者）。
- **成功样貌**：玩家愿意为"我的营地/我的队伍/我的金手指"反复开档、安利、讨论配置与攻略。

## Success Criteria

`[ASSUMPTION]` 以下信号为 MVP 初设，**v0.4 已明确为"定性信号"而非统计门槛**：
- **MVP 达成（功能闭环，可机器判定）**：**1 个基地 + 2 个可探索区 + ≥2 名可招募伙伴 + 世界危机等级 ≥2 级 + 奖励系统可发放 ≥4 次奖励（含 2 次空间扩容）**，跑通"探索→招募→危机升级→奖励强化→结局"完整链路。
- **内测信号（定性，v0.4 修订）**：10 人封闭式内测，**定性观察**——是否出现主动二周目行为、"决策代价感/队伍经营感/金手指爽感"三类主观反馈以访谈方式采集。
  - **修订理由**：原稿设"≥60% 完成一局并二周目、正面反馈 ≥70%"——**10 人样本下 60% = 6 人**，统计效力极弱，作为"通过/不通过"门槛会误导决策。故降级为**定性信号**：看"有没有人自发二周目"，而非"百分比是否达标"。
- **质量信号（可机器判定）**：LLM 幻觉导致的剧情断裂 ≤5%；数值系统不出现"必胜/必死"退化解；**空间戒指不导致难度塌陷**（见风险）。
- **商业（远期，非 MVP 门槛）**：若转发布型，留存/付费模型参考互动剧平台，但 MVP 不考核。

## Scope

**In（v0.4 MVP）：**
- **分区探索**：**3 个区域 = 基地（藏身处）+ 2 个可探索区（超市仓储 / 医院）**，三态地图
- **伙伴招募**：2–3 名可招募伙伴，含专长/忠诚度/**真实资源消耗**
- **世界危机等级**：2 级（极寒 → 疫病），每级解锁 1 个新区域 + 1 段主线
- **奖励系统**：≥4 类奖励（物资/能力/空间扩容/信息），与危机等级挂钩
- **空间戒指**：基础容量 + **2 次扩容升级**（初获 + 配合危机 1→2 的成长节点，确保爽感可体验）
- **支撑**：五维生存面板 + LLM 叙事引擎（**人工主线大纲 + LLM 文本填充** + 规则层校验）+ 决策系统 + 多结局/复盘
- **形态**：文字为主、漫剧风 UI 面板；本地/轻量 Web 可运行

**Out（明确不做）：**
- 实时/准实时 AI 视频生成（成本与延迟硬约束，见红区）
- 大地图程序化生成、无缝大世界、联机、社交
- 发布到短视频平台（备案/审核，见黄区）
- 自建完整魔法战斗系统（法术/异能深度战斗留待后续）
- 自建 IP 宇宙、长线运营
- 关键帧插画（MVP 不做，见 A18）

**Non-goals（防范围蔓延）：**
- 不做"AI 漫剧生产工具"（另一个产品）
- 不服务 B 端 / 教育场景（与公司主业切割）
- 不做开放世界 / Roguelike 全随机（已定分区推进式）
- **不把奖励系统做成"自动通关/无限资源"**（会杀死游戏张力）

## Vision

若验证"异世界末世生存 + 金手指成长"的玩法成立：
- **中期**：区域库 + 伙伴库扩充；**魔法/异能力量体系**深化；**UGC 剧情/地图编辑器**（玩家写区域与分支，平台分发，参考 Yoroll 互动叙事游戏模式，来源：[搜狐](https://www.sohu.com/a/1069007091_100263313)）——**复用 A16 的"人工大纲+AI 填充"结构**作为编辑器骨架。
- **远期**：沉淀为"AI 互动叙事引擎"，可换皮到废土/科幻/悬疑/魔法等多题材，成为轻量互动内容生产底座。
- 落地前提：MVP 内测数据证伪/证实核心假设，再谈扩张。

## 风险与约束（红 / 黄 / 绿）
