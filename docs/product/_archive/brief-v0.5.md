# Product Brief: 末世求生：抉择（暂定代号 WASTELAND CHOICE）

> 版本 **v0.5-draft** · 由 bmad-product-brief（Fast path）起草 · 缺口以 `[ASSUMPTION]` 标注，待评审确认。
> **v0.5 修订重点（核心玩法主线定案）**：① 玩法主线确立为 **「基地经营 × 搜打撤出击」双引擎**；② 探索机制由"线性事件流"升级为 **搜打撤循环**（进入 → 搜刮 → 撤离判定）；③ 确立 **容器二分**——空间戒指 = **安全格**（小容量、失败保底），行囊 = **风险格**（失败全丢）；④ 新增 **基地建设**系统（4 项设施 · 2 级）；⑤ 伙伴改为 **双层制**（叙事核心 + 随机路人）；⑥ 推进单位由"单局 15–30 分钟"改为 **按出击次数推进**，终局为 **存活天数封顶 14 天**。
> v0.4 / v0.3 / v0.2 / v0.1 存档见对应 `_archive-*.md`。

## Executive Summary

一款 **LLM 驱动的异世界末世生存互动沙盒游戏**：玩家扮演一名**携带"奖励系统"金手指的穿越者**，进入一个**存在魔法与空间戒指的末日世界**。玩法由两台引擎咬合驱动——

- **基地经营**：在固定基地中建造与升级设施（床铺 / 火堆 / 净水 / 储物），把出击带回的资源转化为**持久的生存能力**。
- **搜打撤出击**：进入各探索区域搜刮物资，在"贪婪与恐惧"的拉扯中决定**何时撤离**——撤回来才是你的，撤不回来就是别人的。

随**世界危机等级**逐级升级（极寒 → 疫病 → 变异兽潮 → 秩序重建），环境规则改变、新区域与新剧情解锁。主角的**奖励系统**在达成任务/条件时发放物资、能力与空间扩容，形成"个人成长 vs 世界恶化"的双轨张力。

这踩在两个已验证的风口交汇点：① AI 漫剧供给井喷、末世为最高频题材（来源：[投资界/骨朵数据](https://news.pedaily.cn/202606/564702.shtml)）；② **互动化是明确趋势**——番茄平台《全球冰封》让观众以"幸存者"身份做决策、分支结局（来源：[羊城晚报](https://ep.ycwb.com/epaper/ycwb/resfile/2026-07-12/A05/ycwb20260712A05.pdf)）。本产品在"末世 + 互动"之上再加一层**网文式爽感内核**（金手指 + 空间戒指 + 系统流），差异点在**"出击 → 招募 → 经营 → 生存代价"闭环 + 主角金手指成长 + 规则层兜底**。

`[ASSUMPTION]` 本产品定位为**个人兴趣试点 + BMAD 方法验证载体**，非公司主业延伸，故 MVP 极致轻、先自用/小范围内测，规避发布型监管。

## 核心玩法主线（v0.5 定案）

> 本节是 v0.5 的核心改动，其余章节均为其展开。

```
        ┌──────────────── 世界危机等级（天数驱动）────────────────┐
        │  升级：解锁新区域 · 改变环境规则 · 强化奖励强度          │
        └──────────────────────────┬──────────────────────────────┘
                                   ▼
   基地 ──▶ 出击（搜打撤）──▶ 结算 ──┐
（整备/建造/恢复）（进入→搜刮→撤离）（入账/损失/消耗）
    ▲                                │
    └──── 资源投入建设 → 能力提升 ◀───┘
```

**三个支撑点（必须在实现中被保住）：**

1. **撤离决策必须有真实动机**——搜打撤的紧张感来自"战利品随时可能全部失去"。若失败无代价，最优解会退化为"搜无可搜再走"，机制失效。
2. **基地建设必须真的改变能力**——设施不是装饰，每一项都要落成可测的数值修正（恢复速度 / 保暖 / 净水产出 / 储位上限）。
3. **基地是"消耗端"**——资源只有在被建造消耗掉时，出击产出的意义才成立。

## 世界观设定

> 关键前提：**这不是现实世界**。世界观是"科技+魔法"混合的末日废土，为玩法提供额外的资源与力量维度。

- **魔法存在**：世界存在异能者/法师/魔法装置；灾变（末日来临）被设定为与魔法/空间裂缝相关，为后续世界观扩展留口。
- **空间戒指（核心机制 · v0.5 重新定位）**：主角持有的标志性道具，**可收纳远超物理容量的物资装备**，并**可种植/养殖（随身空间）**。v0.5 明确其**在搜打撤中的角色是"安全格"**（见「系统二」），而非无限制豁免。
- **设定程度**：**强设定 / 核心机制**——空间戒指是主角的核心外挂，直接参与玩法（资源携带、风险规避、种植），而非纯背景氛围。`[ASSUMPTION] A12 ✅已确认`

## 主角专属机制：奖励系统

> **系统流金手指**：仅主角持有，其他 NPC 没有。这是爽感与成长的核心引擎。

- **触发方式**：完成任务 / 达成条件 / 首次抵达某区域 / 关键剧情节点 → 发放奖励。
- **奖励类型**：
  1. **物资奖励**（食物、药品、工具——缓解生存压力）
  2. **能力奖励**（如夜间视野、危险感知、魔法亲和、体魄强化）
  3. **空间扩容**（提升空间戒指容量/解锁随身空间功能区）——**v0.5 语义更新：扩容即"安全格变大"**，是本作最直观的成长反馈
  4. **信息奖励**（地图情报、剧情线索、稀有 NPC 位置）
- **设计边界**：
  - **不做纯自动胜利**：奖励是"雪中送炭"而非"直接通关"，避免游戏失去张力。
  - **与危机等级对冲**：世界越危险，系统奖励越强，制造"我在变强，但世界也在恶化"的双轨节奏。`[ASSUMPTION] A13 ✅已确认`
  - **叙事合理性**：奖励系统本身是世界观谜团（为何选中主角？），构成主线悬念钩子。`[ASSUMPTION] A15 — MVP 内仅埋钩子，不揭晓`
- **扩容节奏**：MVP 内**给出 2 次空间扩容**（初获 → 成长 → 配合危机等级 1→2 的第二次扩容），确保"成长爽感"这条核心假设**在 MVP 内可被真实体验到**。`[ASSUMPTION] A14 ✅已确认`

## The Problem

- **现有末世 AI 漫剧是"被动消费"**：观众看分支选择，缺乏"我的选择真的会让队伍饿死/团灭"的**数值化代价感**，沉浸浅、replay 价值低。
- **互动叙事游戏（如 AI Dungeon）缺乏"末世生存 + 成长系统"的硬约束框架**：无资源/体力/温度等生存系统，也无清晰的成长反馈，决策后果飘忽。
- **供给饱和下的审美疲劳**：截至 2026-03 在播 AI 漫剧近 18 万部，末世题材 1.8 万部+，纯内容型产品极易被淹没（来源：[投资界](https://news.pedaily.cn/202606/564702.shtml)）。
- **用户（玩家）痛点**：想要"我主导的末日求生 + 我自己的金手指成长"——能出击搜刮、能囤货（空间戒指）、能拉人入伙、能一步步把基地经营起来，而非"别人写好的爽文"。

## The Solution

以 **LLM（如 DeepSeek / 通义 / 自选 API）+ 规则层（确定性模拟）+ 轻量前端** 构建。**五大系统**：

### 系统一：基地建设（v0.5 新增）

- **定位**：基地是**唯一的固定据点，也是资源的消耗端**。出击带回的资源在此转化为持久能力，构成"赚了要花"的正循环。
- **四类设施（MVP 锁定 4 项 · 2 级）**：

  | 设施 | 作用线 | 一级效果 | 二级效果 |
  |---|---|---|---|
  | 床铺 | 恢复 | 提升每日体力恢复量 | 解锁"重伤"状态的加速恢复 |
  | 火堆 | 保暖 | 降低基地内体温衰减 | 提供范围保暖，抵御极寒期 |
  | 净水 | 资源 | 每日少量净水产出 | 产出提升，并降低队伍饮水消耗 |
  | 储物 | 容量 | 提升基地物资存储上限 | 解锁行囊容量加成（出击携带上限 +） |

- **升级成本**：消耗出击带回的特定资源（工具/材料），成本随等级递增。
- **与"失败惩罚"的关系**：基地是**不会被夺走的安全资产**——出击失败只损失当次携带物，已建成的设施不受影响。这是"失败不等于推倒重来"的底线保障。
- **设计边界**：不做复杂的生产链、不做设施布局规划、不做多基地。`[ASSUMPTION] A22 ✅已确认`

### 系统二：搜打撤出击（v0.5 改写，原"分区探索"）

- **分区地图**：MVP 共 **3 个区域 = 1 个基地 + 2 个可探索区**。探索区有三态（未解锁 / 已知未探 / 已探索）。
  - **首个探索区**：**超市仓储**（危机等级 1 解锁）。`[ASSUMPTION] A7 ✅已确认`
  - **第二探索区**：**医院**（危机等级 2 解锁）。
  - **结构上支持 N 区**（区域配置表驱动，加区 = 加配置）；**MVP 内容锁定 2 个**。`[ASSUMPTION] A25 🟡待确认`
- **搜打撤循环**：

  ```
  出击（消耗体力）→ 进入区域
    → 搜刮（逐次消耗体力，累积战利品）
    → 累积收益边际递减 ↑ / 暴露风险加速上升 ↑↑   ← 两线交叉处即"该撤了"
    → 决策：继续深入 / 前往撤离点撤离
    → 撤离成功：战利品入账
    → 撤离失败：行囊全丢，戒指内保底（见下）
  ```
- **容器二分（v0.5 关键机制）**：
  | 容器 | 容量 | 失败时 | 定位 |
  |---|---|---|---|
  | **物理行囊** | 大 | ❌ **全部损失** | 风险格——大头暴露在风险中 |
  | **空间戒指** | **小**（2–3 格，随扩容增长） | ✅ 保底 | 安全格——保住最值钱的几件 |

  - **为什么必须二分**：若戒指容量大或无条件保底，玩家最优解会变成"搜到就存"，导致失败零代价、撤离决策失去动机，搜打撤退化为扫荡模式。**戒指保底但保不全**，才能同时保住"金手指优势"与"撤离张力"。
  - 参照物：《逃离塔科夫》的安全容器设计——保底机制存在，但装不下大头。
- **失败分级（v0.5 定案）** `[ASSUMPTION] A21 ✅已确认`：

  | 层级 | 触发 | 后果 |
  |---|---|---|
  | 撤离受挫 | 被拦截 / 超时 | 丢部分战利品，可脱身 |
  | **失联** | 体力归零 / 被击倒 | **行囊全丢**（戒指内保底）+ 触发**本次招募机会错过**；主角不死 |
  | 团灭结局 | 体温 / 饥饿归零 | 本局结束（唯一终局路径） |

  - **注意**：单次出击失败**不直接触发结局**——否则 14 天主线根本没机会展开。
- **招募惩罚的可感知性要求**：失败导致"错过本次可招募 NPC"时，**该位置须留下可见痕迹**（废弃营地 / 中断的呼救信号 / 血迹），否则玩家不知道"自己错过了谁"，惩罚形同不存在。`[ASSUMPTION] A23 配套要求`

### 系统三：伙伴招募与队伍管理（v0.5 改为双层制）

- **双层结构** `[ASSUMPTION] A23 ✅已确认`：

  | 类型 | 产生方式 | 特征 |
  |---|---|---|
  | **叙事核心伙伴** | 固定，剧情节点解锁 | 有名有姓、有背景故事与专属剧情线（如"苏晚"），**不会随机消失** |
  | **随机路人** | 出击中随机遭遇 | LLM 生成姓名/专长/诉求，数值向，**可失去** |

  - **为什么必须分层**：随机生成的 NPC 不可能承载"专属剧情线"，二者在逻辑上互斥。分层后，"随机触发招募"与"角色立体"两个需求同时成立。
- **招募途径**：出击中遭遇 NPC（求助/敌对/中立），通过决策（给物资/施救/交易）招募。
- **伙伴属性**：专长（战斗/医疗/工程/交涉/采集）+ 独立 sanity/忠诚度 + 个人诉求（未满足可能离队/反水）。
- **队伍负担**：食物/药品消耗随人数**真实增长**——"多一个帮手还是多一张嘴"。`[ASSUMPTION] A10 ✅已确认（保留真实张力）`
  - **戒指的定位**：戒指提供**延迟缓冲**（预存物资平抑短期波动），**不消除**队伍规模的长期人均消耗增长。
  - ✂️ **已否决的写法**：v0.3 曾写"戒指可**部分对冲**队伍负担"，与"轻度负担"叠加后会导致**招募零代价**。v0.4 起明确二者**不得叠加削弱**。

### 系统四：世界危机等级

- **四级危机轴**：`极寒 → 疫病 → 变异兽潮 → 秩序重建`；每升一级：① 环境规则改变；② 解锁新区域；③ 推进主线章节。
- **升级触发**：**存活天数为主触发**（关键节点可提前、玩家行动可延后），制造"要不要苟"的策略。
- **与天数 / 区域的对应（v0.5 对齐）**：

  | 等级 | 主题 | 天数区间 | 解锁区域 |
  |---|---|---|---|
  | 1 | 极寒 | 第 1–7 天 | 超市仓储（首个探索区） |
  | 2 | 疫病 | 第 8–14 天 | 医院 |
  | 3 | 变异兽潮 | （MVP 外） | （MVP 外） |
  | 4 | 秩序重建 | （MVP 外） | （MVP 外） |

  `[ASSUMPTION] A26 🟡待确认（先定 14 天，内测标定）`
- **危机升级也是奖励系统的强化窗口**——世界越难，系统奖励越强（双轨对冲）。

### 系统五：主角奖励系统

- **触发**：任务/条件/首次抵达/剧情节点。
- **奖励**：物资 / 能力 / 空间扩容 / 信息（详见「主角专属机制」）。
- **定位**：主角独有成长引擎，提供**爽感节奏**与**长期目标感**，同时是世界观悬念的载体。

### 支撑系统

- **叙事引擎**：
  - **主线章节**：**人工写大纲**（章节节点、关键决策、结局分支由人定）+ **LLM 填充场景文本**。`[ASSUMPTION] A16 ✅已确认`
  - **探索事件**：LLM 生成 + 规则层校验（数值落点必须确定性）。
  - **设计理由**：纯 LLM 生成主线会导致剧情飘忽、结局不可控，与"规则层兜底幻觉"的设计纪律冲突；全人工则工程量过大。**大纲人工 + 文本 AI** 是质量与成本的平衡点，且该结构可**直接复用**为后续 UGC 剧情编辑器的模板。
- **生存数值面板**：体温 / 饥饿 / 体力 / 资源 / sanity / 队伍状态，漫剧风 UI。
  - `[ASSUMPTION] A17 ✅已确认` **sanity 取向**：保留但**弱化惩罚**（影响局部选项/对话倾向，不直接致死），避免"又爽又丧"的体验冲突。
- **决策系统**：关键节点 2–4 选项，绑定数值变化；蝴蝶效应。
- **多结局 + 复盘**：存档、分支图、结局归因。
- **画面策略（后置）**：MVP 纯文字+面板；后续**关键帧预生成插画**补漫剧质感，绝不实时生成视频。
  - `[ASSUMPTION] A18 ✅已确认` MVP **不做插画**；插画仅为 MVP 验证通过后的**可选加分项**。

## What Makes This Different

- **"基地经营 + 搜打撤 + 系统流金手指"三层叠加**：市面竞品要么纯写实生存、要么纯爽文系统流、要么纯撤离玩法；本产品用**同一套数值系统**把"生存压力""风险博弈"与"成长爽感"焊在一起。
- **容器二分改写风险公式**：行囊=风险格、戒指=安全格，"哪几件最值得保底"成为每轮出击的新决策层——**保底机制同时是决策来源**。
- **决策有真实代价**：继续深入/及时撤离、施救/抛弃、招募/独行，都真的改动资源与队伍状态——**主体责任感**。
- **规则层兜底 LLM 幻觉**：确定性数值/状态机约束 LLM，保证剧情连贯、数值平衡（竞品纯 LLM 易崩）。
- **不做内容军备竞赛**：拼**玩法深度 + 成长节奏 + replay 价值**。
- 诚实声明：若壁垒仅是"文案 + 套壳 LLM"，则**无技术护城河**；护城河在**数值平衡 + 系统设计（出击/经营/招募/危机/奖励）+ 剧情分支质量**。`[ASSUMPTION]`

## Who This Serves

- **核心用户（远期假设，MVP 阶段不作为验收项）**：18–35 岁男性为主，网文（系统流/末世流/随身空间流）、短剧、生存与撤离类游戏（《明日之后》《饥荒》《归家异途》《这是我的战争》《暗区突围》）玩家，C 端，追求"主导感 + 经营感 + 风险博弈 + 成长爽感"。`[ASSUMPTION] A2 — ⬇️已降级为远期假设`
  - **降级理由**：A3 已定"先自用/demo、不发布"，MVP 阶段唯一用户是开发者本人。此时固化 C 端画像**无处落地**。待进入"是否发布"决策时再启用。
- **次要用户**：互动叙事爱好者、AI 内容创作者（潜在 UGC 剧情作者）。
- **成功样貌**：玩家愿意为"我的基地/我的队伍/我的金手指"反复开档、安利、讨论配置与攻略。

## Success Criteria

`[ASSUMPTION]` 以下信号为 MVP 初设，**已明确为"定性信号"而非统计门槛**：

- **MVP 达成（功能闭环，可机器判定）**：**1 个基地（4 项设施可建至 2 级）+ 2 个可探索区 + ≥2 名可招募伙伴 + 世界危机等级 ≥2 级 + 奖励系统可发放 ≥4 次奖励（含 2 次空间扩容）**，跑通"出击 → 招募 → 危机升级 → 奖励强化 → 基地升级 → 结局"完整链路。
- **内测信号（定性）**：10 人封闭式内测，**定性观察**——是否出现**主动发起新一轮出击**的行为；"撤离决策的紧张感 / 基地经营感 / 金手指爽感"三类主观反馈以访谈方式采集。
  - **修订说明**：原口径"单局 15–30 分钟"与"二周目行为"已随 v0.5 推进单位变更而**作废**——不设单次时长后，"一局"可能长达 14 天，二周目概念不再适用。替代信号为**"是否主动发起第三、第四次出击"**。
- **质量信号（可机器判定）**：LLM 幻觉导致的剧情断裂 ≤5%；数值系统不出现"必胜/必死"退化解；**戒指不导致撤离决策失效**（存在测试用例：行囊满载时失败会造成可感知损失）。
- **商业（远期，非 MVP 门槛）**：若转发布型，留存/付费模型参考互动剧平台，但 MVP 不考核。

## Scope

**In（v0.5 MVP）：**
- **基地建设**：4 项设施（床铺 / 火堆 / 净水 / 储物）· 可建至 2 级；消耗出击资源升级
- **搜打撤出击**：**3 个区域 = 基地 + 2 个可探索区（超市仓储 / 医院）**，三态地图；进入 → 搜刮 → 撤离判定完整循环
- **容器二分**：行囊（风险格，失败全丢）+ 空间戒指（安全格，2–3 格起，失败保底）
- **伙伴招募**：双层制——2 名叙事核心 + N 名随机路人，含专长/忠诚度/真实资源消耗
- **世界危机等级**：2 级（极寒 → 疫病），对应第 1–7 天 / 第 8–14 天，每级解锁 1 个新区域 + 1 段主线
- **奖励系统**：≥4 类奖励（物资/能力/空间扩容/信息），与危机等级挂钩
- **空间戒指**：安全格容量 + **2 次扩容**（初获 + 配合危机 1→2 的成长节点）
- **终局**：存活满 **14 天** 触发结算，或体温/饥饿归零触发团灭
- **支撑**：五维生存面板 + LLM 叙事引擎（人工大纲 + LLM 填充 + 规则层校验）+ 决策系统 + 多结局/复盘
- **形态**：文字为主、漫剧风 UI 面板；桌面 Web 可运行

**Out（明确不做）：**
- 实时/准实时 AI 视频生成（成本与延迟硬约束，见红区）
- 大地图程序化生成、无缝大世界、联机、社交
- 发布到短视频平台（备案/审核，见黄区）
- 自建完整魔法战斗系统（法术/异能深度战斗留待后续）
- 自建 IP 宇宙、长线运营
- 关键帧插画（MVP 不做，见 A18）
- 复杂生产链、设施布局规划、多基地（v0.5 明确排除）

**Non-goals（防范围蔓延）：**
- 不做"AI 漫剧生产工具"（另一个产品）
- 不服务 B 端 / 教育场景（与公司主业切割）
- 不做开放世界 / 全随机 Roguelike（已定分区推进式）
- **不把奖励系统做成"自动通关/无限资源"**（会杀死游戏张力）
- **不让空间戒指成为"无限豁免"**（会杀死撤离决策）

## Vision

若验证"异世界末世生存 + 金手指成长"的玩法成立：
- **中期**：区域库 + 伙伴库扩充；**魔法/异能力量体系**深化；**UGC 剧情/地图编辑器**（玩家写区域与分支，平台分发，参考 Yoroll 互动叙事游戏模式，来源：[搜狐](https://www.sohu.com/a/1069007091_100263313)）——**复用 A16 的"人工大纲+AI 填充"结构**作为编辑器骨架。
- **远期**：沉淀为"AI 互动叙事引擎"，可换皮到废土/科幻/悬疑/魔法等多题材，成为轻量互动内容生产底座。
- 落地前提：MVP 内测数据证伪/证实核心假设，再谈扩张。
