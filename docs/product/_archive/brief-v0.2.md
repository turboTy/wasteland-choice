# Product Brief: 末世求生：抉择（暂定代号 WASTELAND CHOICE）

> 版本 **v0.2-draft** · 由 bmad-product-brief（Fast path）起草 · 缺口以 `[ASSUMPTION]` 标注，待评审确认。
> **v0.2 相对 v0.1 的结构性升级**：单一"决策游戏"→**分区推进式生存沙盒**（探索区域 + 招募伙伴 + 世界危机等级推进）。

## Executive Summary

一款 **LLM 驱动的末世生存互动沙盒游戏**：玩家以"幸存者"身份进入废土，**在分区地图上探索不同区域搜集物资、招募伙伴、搭建藏身处**；随**世界危机等级**逐级升级（极寒 → 疫病 → 变异兽潮 → 秩序重建），环境规则改变、新区域与新剧情解锁。每一次探索与决策都被**生存数值面板**（体温、饥饿、体力、资源、sanity、队伍状态）以确定性代价反馈，多分支、多结局。

这踩在两个已验证的风口交汇点：① AI 漫剧供给井喷、末世为最高频题材（来源：[投资界/骨朵数据](https://news.pedaily.cn/202606/564702.shtml)）；② **互动化是明确趋势**——番茄平台《全球冰封：我打造了末日安全屋》让观众以"幸存者"身份做资源分配、陌生人敲门等决策，分支结局（来源：[羊城晚报](https://ep.ycwb.com/epaper/ycwb/resfile/2026-07-12/A05/ycwb20260712A05.pdf)）。本产品差异点不在"又一个末世剧"，而在**"探索 → 招募 → 生存代价"的完整闭环 + 规则层兜底**——这是纯观看型漫剧做不到的。

`[ASSUMPTION]` 本产品定位为**个人兴趣试点 + BMAD 方法验证载体**，非公司主业延伸，故 MVP 极致轻、先自用/小范围内测，规避发布型监管。

## The Problem

- **现有末世 AI 漫剧是"被动消费"**：观众看分支选择，但缺乏"我的选择真的会让队伍饿死/团灭"的**数值化代价感**，沉浸浅、replay 价值低。
- **互动叙事游戏（如 AI Dungeon）缺乏"末世生存"的硬约束框架**：无资源/体力/温度等生存系统，决策后果飘忽，探索与招募无系统化支撑。
- **供给饱和下的审美疲劳**：截至 2026-03 在播 AI 漫剧近 18 万部，末世题材 1.8 万部+，纯内容型产品极易被淹没（来源：[投资界](https://news.pedaily.cn/202606/564702.shtml)）。
- **用户（玩家）痛点**：想要"我主导的末日求生"——能去探索、能拉人入伙、能看着自己的营地一点点活下来；而非"别人写好的爽文"。

## The Solution

以 **LLM（如 DeepSeek / 通义 / 自选 API）+ 规则层（确定性模拟）+ 轻量前端** 构建。三个核心系统：

### 系统一：分区探索（探索区域寻找物资）
- **分区地图**：末日世界划分为若干区域（藏身处 / 居民区 / 超市仓储 / 医院 / 工业区 / 荒野…），由"已探索 → 已知未探 → 未解锁"三态管理。
- **探索循环**：玩家选择目标区域 → 消耗时间/体力 → 触发**探索事件**（物资、遭遇、危险、NPC）→ 带战利品返回或就地决策。
- **风险回报**：越深/越远的区域物资越好，但遭遇战/辐射/寒潮风险越高。探索不是无脑刷，是**资源-风险权衡**。
- **区域解锁**：由**世界危机等级**驱动——危机升级才开放新区域，形成天然的剧情推进节奏。

### 系统二：伙伴招募与队伍管理（招募伙伴）
- **招募途径**：探索中遭遇 NPC（求助/敌对/中立），通过决策（给物资 / 施救 / 交易）招募成伙伴。
- **伙伴属性**：每人带 1–2 项专长（战斗 / 医疗 / 工程 / 交涉 / 采集）+ 独立 sanity / 忠诚度 + 个人诉求（未满足可能离开或反水）。
- **队伍数值**：食物/药品消耗随人数增加——**招募不是纯增益，是资源负担**，制造"多一个帮手还是多一张嘴"的抉择。
- **伙伴叙事**：伙伴有背景故事与专属剧情线，构成剧情深度与情感锚点。

### 系统三：世界危机等级（末日模式升级推进剧情）
- **四级危机轴**（示例）：`极寒 → 疫病 → 变异兽潮 → 秩序重建`；每升一级：
  1. **环境规则改变**（如极寒期体温掉得更快、疫病期开启感染数值）；
  2. **解锁新区域**（驱动系统一）；
  3. **推进主线剧情章节**（驱动叙事）。
- **升级触发**：由存活天数 / 关键剧情节点 / 玩家行动（如修好电台）驱动，玩家可部分影响升级时机。
- **设计意图**：危机等级 = 内容节奏的节拍器，把"线性看剧情"改造成"在压力下做选择"。

### 支撑系统（v0.1 已定，保留）
- **叙事引擎**：LLM 生成场景文本 + 依据玩家状态与选择推演剧情；**规则层（非纯 LLM）保证数值一致性**，抑制幻觉。
- **生存数值面板**：体温 / 饥饿 / 体力 / 资源 / sanity / 队伍状态，漫剧风 UI，实时反映代价。
- **决策系统**：关键节点 2–4 选项，绑定数值变化；部分选项触发蝴蝶效应（短期甜、长期毒）。
- **多结局 + 复盘**：存档、分支图、结局归因。
- **画面策略（后置）**：MVP 纯文字+面板；后续**关键帧预生成插画**补漫剧质感，绝不实时生成视频。

`[ASSUMPTION]` 画面采用"漫剧风 UI + 关键帧插画"而非实时视频，是成本与体验的权衡结论（见风险红区）。

## What Makes This Different

- **"探索 + 招募 + 生存代价"三位一体的闭环**：竞品要么只看剧情（漫剧）、要么只聊天（AI Dungeon）、要么只打工（放置类）；本产品把三者用**同一套数值系统**串起来。
- **决策有真实代价**：开门/拒绝、施救/抛弃、招募/独行，都真的改动资源与队伍状态，甚至团灭——**主体责任感**是观看型漫剧给不了的。
- **规则层兜底 LLM 幻觉**：确定性数值/状态机约束 LLM，保证剧情连贯、数值平衡（竞品纯 LLM 易崩）。
- **不做内容军备竞赛**：不拼产量、不拼画面堆料，拼**玩法深度与 replay 价值**——在 18 万部供给里靠差异化而非流量。
- 诚实声明：若壁垒仅是"文案 + 套壳 LLM"，则**无技术护城河**；护城河在**数值平衡 + 系统设计（探索/招募/危机）+ 剧情分支质量**。`[ASSUMPTION]`

## Who This Serves

- **核心用户**：18–35 岁男性为主，网文/短剧/生存游戏（如《明日之后》《饥荒》《归家异途》）玩家，C 端，追求"主导感 + 经营感 + 决策爽感"。`[ASSUMPTION]`
- **次要用户**：互动叙事爱好者、AI 内容创作者（潜在 UGC 剧情作者）。
- **成功样貌**：玩家愿意为"我的营地/我的队伍"反复开档、向朋友安利、讨论区域攻略与伙伴搭配。

## Success Criteria

`[ASSUMPTION]` 以下量化值为 MVP 初设，需校准：
- **MVP 达成**：可玩闭环——**≥3 个可探索区域 + ≥2 名可招募伙伴 + 世界危机等级 ≥2 级**，跑通"探索→招募→危机升级→结局"完整链路。
- **内测信号**：10 人封闭式内测，≥60% 完成一局并主动二周目；"决策代价感/队伍经营感"正面反馈 ≥70%。
- **质量信号**：LLM 幻觉导致的剧情断裂 ≤5%（规则层兜底后）；数值系统不出现"必胜/必死"的退化解。
- **商业（远期，非 MVP 门槛）**：若转发布型，留存/付费模型参考互动剧平台，但 MVP 不考核。

## Scope

**In（v0.2 MVP）：**
- **分区探索**：3 个区域（藏身处 + 2 个可探索区），三态地图管理
- **伙伴招募**：2–3 名可招募伙伴，含专长/忠诚度/资源消耗
- **世界危机等级**：2 级（如"极寒"→"疫病"），每级解锁 1 新区域 + 1 段主线
- **支撑**：五维生存面板 + LLM 叙事引擎（规则层约束）+ 决策系统 + 多结局/复盘
- **形态**：文字为主、漫剧风 UI 面板；本地/轻量 Web 可运行

**Out（明确不做）：**
- 实时/准实时 AI 视频生成（成本与延迟硬约束，见红区）
- 大地图程序化生成、无缝大世界、联机、社交
- 发布到短视频平台（备案/审核，见黄区）
- 自建 IP 宇宙、长线运营

**Non-goals（防范围蔓延）：**
- 不做"AI 漫剧生产工具"（那是另一个产品）
- 不服务 B 端 / 教育场景（与公司主业切割）
- **不做开放世界/Roguelike 全随机**（已定分区推进式，见 A8）

## Vision

若验证"探索 + 招募 + 危机推进"的生存沙盒玩法成立：
- **中期**：区域库 + 伙伴库扩充；**UGC 剧情/地图编辑器**（玩家写区域与分支，平台分发，参考 Yoroll 互动叙事游戏模式，来源：[搜狐](https://www.sohu.com/a/1069007091_100263313)）。
- **远期**：沉淀为"AI 互动叙事引擎"，可换皮到废土/科幻/悬疑等多题材，成为轻量互动内容生产底座。
- 落地前提：MVP 内测数据证伪/证实核心假设，再谈扩张。
