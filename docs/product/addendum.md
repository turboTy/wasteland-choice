# Addendum: WASTELAND CHOICE 玩法设计详案

> 本文件是 BRIEF v0.3 的配套深度内容（BMAD 约定：细节归 addendum，BRIEF 保持 1–2 页可读）。
> 系统细设（分区探索 / 伙伴招募 / 世界危机等级 / **世界观与奖励系统**）在此展开，作为 `bmad-prd` 的直接输入。

## 一、系统一：分区探索

### 1.1 地图状态机
| 状态 | 含义 | 玩家可见信息 |
|---|---|---|
| 🔒 未解锁 | 危机等级不足 | 仅名称轮廓 / 未知 |
| 🌫 已知未探 | 已解锁未进入 | 区域名 + 风险等级 + 传闻收益 |
| 🏠 已探索 | 进入过 | 完整信息 + 可重复进入 + 剩余物资状态 |

### 1.2 探索循环
```
选择目标区域 → 判定消耗(时间/体力/队伍补给)
   → 触发 1~3 个探索事件(物资 / 遭遇 / NPC / 危险)
   → 逐事件决策(战斗/躲藏/交涉/撤退)
   → 结算：带回物资 + 队伍状态变化 + 触发剧情钩子
   → 返回藏身处(或就地扎营/失联)
```

### 1.3 区域属性表（MVP 3 区示例）
| 区域 | 风险 | 主要产出 | 特殊机制 | 解锁条件 |
|---|---|---|---|---|
| 藏身处（基地） | 无 | 建造/休息/分配 | 安全区，队伍在此恢复 | 初始 |
| 居民区废墟 | 低 | 食物、衣物、药品 | 遭遇幸存者/NPC 概率高（招募主战场） | 初始 |
| 超市仓储 | 中 | 大量食物、工具 | 高价值 → 吸引掠夺者（战斗风险） | 危机 1 级 |
| 医院 | 高 | 药品、医疗器材、感染线索 | 疫病期价值翻倍；丧尸/感染者密度高 | 危机 2 级 |

### 1.4 关键设计约束
- 每次探索有**明确机会成本**（体力/时间有限，一天只能选有限区域）。
- 引入**行囊上限**：带回物资有容量限制，逼迫取舍（拿食物还是药品）。
- **不死循环**：若资源耗尽，须有"绝境翻盘"路径（如冒险去高风险区），避免卡死。

## 二、系统二：伙伴招募与队伍管理

### 2.1 伙伴数据模型
| 字段 | 说明 |
|---|---|
| 专长 | 战斗 / 医疗 / 工程 / 交涉 / 采集（1–2 项） |
| 数值 | 体力、sanity、忠诚度（0–100） |
| 消耗 | 每日食物/药品消耗（随专长与状态浮动） |
| 诉求 | 个人目标（如"找回妹妹""要药品"）；未满足 → 忠诚度下降 → 可能离队/反水 |
| 剧情线 | 专属支线，随忠诚度/危机推进解锁 |

### 2.2 招募决策矩阵
| NPC 情境 | 选项 | 代价/收益 |
|---|---|---|
| 受伤求助者 | 施救 | -药品，+潜在伙伴（若存活） |
| | 无视 | 0 消耗，-1 sanity（道德负担） |
| 敌对掠夺者 | 战斗 | 高风险，击败可夺物资/俘虏招募 |
| | 谈判 | 交涉专长加成，可能以物资换和平 |
| 交易商人 | 交换 | 物资置换，可能带来稀有物件 |

### 2.3 队伍负担机制（A10 待定项）
- **保留版（拟）**：人数 ↑ → 每日消耗 ↑ → 制造"多一个帮手 or 多一张嘴"。
- **简化版**：招募纯增益，消耗固定。→ 建议：MVP 先用**轻度负担**（消耗随人数线性增长但不惩罚），既保留抉择又不劝退。

### 2.4 忠诚度与流失
- 忠诚度受：诉求满足度、sanity 事件、食物短缺、决策倾向（冷酷/仁慈）影响。
- 流失方式：抱怨 → 拒绝执行 → 离队（带走私人物资）→ 反水（极端）。
- **戏剧性**：忠诚度系统是"决策有代价"在伙伴线上的体现。

## 三、系统三：世界危机等级

### 3.1 危机轴与规则改变
| 等级 | 主题 | 环境规则改变 | 解锁区域 | 主线推进 |
|---|---|---|---|---|
| 1 | 极寒 | 体温下降加快；需保暖/生火 | 超市仓储 | 第 1 章：找到可靠藏身处 |
| 2 | 疫病 | 新增"感染"数值；药品稀缺 | 医院 | 第 2 章：找到病源/疫苗线索 |
| 3 | 变异兽潮 | 战斗强度激增；夜间危险 | 工业区/荒野 | 第 3 章：抵御兽潮 |
| 4 | 秩序重建 | 从求生转向重建（潜在结局钩子） | — | 终局/多结局 |

### 3.2 升级触发机制
- **自动推进**：存活天数达阈值。
- **剧情推进**：完成关键节点（如修好电台、找到疫苗）。
- **玩家影响**：部分升级可**延后**（延迟成本 = 储备不足时更凶），制造"要不要苟"的策略。

### 3.3 与另两个系统的耦合
```
危机等级 ──► 解锁新区域（系统一）
         ──► 改变环境规则（数值系统）
         ──► 推进主线章节（叙事引擎）
         ◄── 玩家行动可部分影响升级时机
伙伴招募 ──► 影响探索成功率与战斗结果（系统一）
         ──► 消耗资源（数值系统）
区域探索 ──► 产出资源养活队伍（系统二）
         ──► 触发剧情钩子推动危机（系统三）
```
三个系统互为因果闭环——这是 BRIEF 中"三位一体"差异化的具体落地。

## 六、世界观设定详案（v0.3 新增）

### 6.1 世界性质
- **非现实世界**：科技残骸 + 魔法/异能共存的末日废土。
- **灾变成因（暂定）**：空间裂缝/魔法灾难导致文明崩塌——为"世界为何末日"提供世界观级解释，也为后续扩展留口。`[ASSUMPTION] A15`

### 6.2 魔法/异能的设定边界（防设定打架）
| 设定项 | 规则 | 对玩法的影响 |
|---|---|---|
| 异能者/法师 | NPC 与主角均可有；技能非主角独有 | 伙伴专长可含"异能"；探索遭遇可含魔法危机 |
| 魔法装置 | 遗迹/废墟中可拾取 | 新增一类高价值探索产出 |
| 空间戒指 | **主角独有（金手指）** | 核心机制，见 6.3 |
| 魔法与数值 | 所有魔法效果须落到既有数值层（体力/sanity/资源） | 规则层统一校验，禁止"魔法无视数值" |

**设计纪律**：任何魔法设定，都必须能翻译成"对既有数值层的确定性改动"，否则不进设定——这是防止世界观与规则层打架的硬约束。

### 6.3 空间戒指设计
| 属性 | 规则 |
|---|---|
| 基础容量 | 有限（如 16 格），开局非无双 |
| 扩容途径 | **仅通过主角奖励系统解锁**（见第七节） |
| 随身空间（可选） | 中期解锁：可种植/养殖，提供稳定产出 |
| 平衡约束 | 容量增长须与危机等级同步——世界越难，戒指才越大，否则难度塌陷 |

**关键权衡（红区预警）**：空间戒指解决了"行囊上限"的憋屈感，但也可能**削弱末日紧张感**。平衡方案：
- 戒指**只解决"携带"**，不解决"安全"——藏身仍受威胁；
- 戒指内物资若**全灭**（主角团灭）应真正损失，保留赌注；
- 扩容节奏受危机等级与奖励系统双重约束，不自由膨胀。

## 七、主角奖励系统详案（v0.3 新增）

### 7.1 系统定位
- **系统流金手指**：仅主角持有，NPC 无。属网文"系统文"经典设定，提供爽感与目标感。
- **叙事身份**：奖励系统本身是主线悬念（为何选中主角？系统从何而来？），构成长期追更钩子。`[ASSUMPTION] A15`

### 7.2 触发与奖励矩阵
| 触发类型 | 示例 | 奖励类型 | 强度 |
|---|---|---|---|
| 首次抵达区域 | 首次进入医院 | 信息（地图/线索） | 低 |
| 完成生存任务 | 存活满 N 天、队伍不散 | 物资 | 低-中 |
| 关键剧情节点 | 修好电台、找到疫苗线索 | 能力 / 空间扩容 | 中-高 |
| 逆境达成 | 绝境翻盘、零伤亡撤离 | 能力（特殊） | 高 |

### 7.3 奖励四类（与 BRIEF 一致）
1. **物资**：食物/药品/工具——缓解生存压力。
2. **能力**：夜间视野、危险感知、魔法亲和、体魄强化——提升生存与探索半径。
3. **空间扩容**：提升戒指容量/解锁随身空间——成长核心。
4. **信息**：地图情报、剧情线索、稀有 NPC 位置——推动探索与招募。

### 7.4 平衡纪律（红区）
- **不做自动通关**：奖励是"雪中送炭"，非"直接胜利"。任何奖励不得跳过硬约束（如资源耗尽仍会死）。
- **双轨对冲**：世界危机升级 → 奖励强度同步提升，保持"我在变强，世界更难"的动态平衡。
- **可预期但不无聊**：奖励规则透明（玩家可规划），但内容有随机性（避免公式化）。

## 八、四系统耦合闭环（v0.3 更新）

```
奖励系统 ──► 空间扩容 → 强化"分区探索"的携带/收益
         ──► 能力奖励 → 提升探索/招募成功率
         ──► 物资奖励 → 反哺"伙伴招募"的队伍负担

世界危机 ──► 解锁新区域（探索）
         ──► 提升难度 → 触发更强奖励（奖励系统）
         ──► 推进主线（叙事）

分区探索 ──► 产出物资养队伍（招募）
         ──► 触发剧情节点（危机 + 奖励）

伙伴招募 ──► 战力/专长反哺探索
         ──► 消耗资源（与奖励/戒指对冲）
```

**闭环意义**：四个系统共用同一个数值层，互为因果——玩家任一动线都会牵动其余三条，这是"生存 + 成长"双引擎的具体落地。
