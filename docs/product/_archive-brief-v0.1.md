# Product Brief: 末世求生：抉择（暂定代号 WASTELAND CHOICE）

> 版本 v0.1-draft · 由 bmad-product-brief（Fast path）起草 · 缺口以 `[ASSUMPTION]` 标注，待评审确认。
> 所有 `[ASSUMPTION]` 均为推理占位，非定论，请逐条核对或推翻。

## Executive Summary

一款 **LLM 驱动的末世生存互动小游戏**：玩家以"幸存者"身份进入末日场景，通过**关键决策**推进剧情，系统以**生存数值面板**（体温、饥饿、体力、资源、sanity）实时反馈选择后果，多分支、多结局。画面以**漫剧风格 UI**（漫画质感 + 关键帧插画）呈现，但 MVP 阶段以文字叙事 + 数值面板为核心，**不实时生成视频**。

这踩在两个已验证的风口交汇点：① AI 漫剧供给井喷、末世为最高频题材（来源：[投资界/骨朵数据](https://news.pedaily.cn/202606/564702.shtml)）；② **互动化是明确趋势**——番茄平台《全球冰封：我打造了末日安全屋》让观众以"幸存者"身份做资源分配、陌生人敲门等决策，分支结局（来源：[羊城晚报](https://ep.ycwb.com/epaper/ycwb/resfile/2026-07-12/A05/ycwb20260712A05.pdf)）。本产品的差异点不在"又一个末世剧"，而在**决策的真实代价与蝴蝶效应**——这是纯观看型漫剧做不到的。

`[ASSUMPTION]` 本产品当前定位为**个人兴趣试点 + BMAD 方法验证载体**，非公司主业延伸，故 MVP 极致轻、先自用/小范围内测，规避发布型监管。

## The Problem

- **现有末世 AI 漫剧是"被动消费"**：观众看分支选择，但缺乏"我的选择真的会让我饿死/团灭"的**数值化代价感**，沉浸浅、 replay 价值低。
- **互动叙事游戏（如 AI Dungeon）缺乏"末世生存"的硬约束框架**：无资源/体力/温度等生存系统，决策后果飘忽。
- **供给饱和下的审美疲劳**：截至 2026-03 在播 AI 漫剧近 18 万部，末世题材 1.8 万部+，纯内容型产品极易被淹没（来源：[投资界](https://news.pedaily.cn/202606/564702.shtml)）。
- **用户（玩家）痛点**：想要"我主导的末日求生"，而非"别人写好的爽文"；想要决策有分量、有后果、可复盘。

## The Solution

以 **LLM（如 DeepSeek / 通义 / 自选 API）+ 轻量前端** 构建：

1. **叙事引擎**：LLM 生成场景文本 + 依据玩家状态与选择推演剧情分支；规则层（非纯 LLM）保证数值一致性，抑制幻觉。
2. **生存数值面板**：体温 / 饥饿 / 体力 / 资源 / sanity 五维，UI 呈漫剧风（参考《全球冰封》的"幸存者面板"），实时反映决策代价。
3. **决策系统**：关键节点给 2–4 选项，选项绑定资源/数值变化；部分选项触发蝴蝶效应（短期甜、长期毒）。
4. **多结局 + 复盘**：存档、分支图、结局归因，提升 replay 价值。
5. **画面策略（后置）**：MVP 纯文字+面板；后续以**关键帧预生成插画**（图生图，非实时视频）补漫剧质感，绝不实时生成视频。

`[ASSUMPTION]` 画面采用"漫剧风 UI + 关键帧插画"而非实时视频，是成本与体验的权衡结论（见风险红区）。

## What Makes This Different

- **决策有真实代价**：数值系统让"开门还是拒绝陌生人"真的导致资源增减、sanity 波动、甚至团灭——这是观看型漫剧无法提供的**主体责任感**。
- **规则层兜底 LLM 幻觉**：用确定性的数值/状态机约束 LLM 自由发挥，保证剧情连贯与平衡（竞品纯 LLM 易崩）。
- **不做内容军备竞赛**：不拼产量、不拼画面堆料，拼**玩法深度与 replay 价值**——在 18 万部供给里靠差异化而非流量。
- 诚实声明：若壁垒仅是"文案 + 套壳 LLM"，则**无技术护城河**，护城河在**数值平衡设计 + 剧情分支质量 + 社区 UGC 扩展**。`[ASSUMPTION]`。

## Who This Serves

- **核心用户**：18–35 岁男性为主，网文/短剧/生存游戏（如《明日之后》《饥荒》）玩家，C 端，追求"主导感 + 决策爽感"。`[ASSUMPTION]`
- **次要用户**：互动叙事爱好者、AI 内容创作者（潜在 UGC 剧情作者）。
- **成功样貌**：玩家愿意为"我的末日选择"反复开档、向朋友安利、讨论分支攻略。

## Success Criteria

`[ASSUMPTION]` 以下量化值为 MVP 初设，需校准：
- **MVP 达成**：可玩闭环（开局→≥3 个关键决策点→≥2 个结局），单一场景（如"寒潮避难所"）跑通。
- **内测信号**：10 人封闭式内测，≥60% 完成一局并主动二周目；决策"后悔感/代价感"正面反馈 ≥70%。
- **质量信号**：LLM 幻觉导致的剧情断裂 ≤5%（规则层兜底后）。
- **商业（远期，非 MVP 门槛）**：若转发布型，留存/付费模型参考互动剧平台，但 MVP 不考核。

## Scope

**In（v0.1 MVP）：**
- 单一末日场景 + 五维生存面板 + LLM 叙事引擎（规则层约束）
- 关键决策点（≥3）+ 多分支（≥2 结局）+ 复盘
- 文字为主、漫剧风 UI 面板；本地/轻量 Web 可运行

**Out（明确不做）：**
- 实时/准实时 AI 视频生成（成本与延迟硬约束，见红区）
- 多场景大世界、联机、社交
- 发布到短视频平台（备案/审核，见黄区）
- 自建 IP 宇宙、长线运营

**Non-goals（防范围蔓延）：**
- 不做"AI 漫剧生产工具"（那是另一个产品）
- 不服务 B 端 / 教育场景（与公司主业切割）

## Vision

若验证"决策有代价"的互动生存玩法成立：
- **中期**：多场景剧情库 + UGC 剧情编辑器（玩家写分支，平台分发，参考 Yoroll 互动叙事游戏模式，来源：[搜狐](https://www.sohu.com/a/1069007091_100263313)）。
- **远期**：沉淀为"AI 互动叙事引擎"，可换皮到废土/科幻/悬疑等多题材，成为轻量互动内容生产底座。
- 落地前提：MVP 内测数据证伪/证实核心假设，再谈扩张。
