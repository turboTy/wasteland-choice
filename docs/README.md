## 产品一句话

玩家扮演携带**奖励系统金手指**的穿越者，进入**存在魔法与空间戒指**的末日世界：分区探索找物资、招募伙伴、随**世界危机等级**升级推进剧情，靠**奖励系统**成长，在"生存压力"与"成长爽感"的双轨中求生。

## 核心设计原则（红线）

1. **规则层兜底 LLM**：所有魔法/奖励效果必须落到既有数值层（体温/饥饿/体力/资源/sanity/队伍）的确定性改动，禁止"无视数值"。
2. **金手指不无双**：空间戒指容量随奖励系统成长解锁；奖励是"雪中送炭"非"自动通关"。
3. **双轨对冲**：世界危机升级 → 奖励强度同步提升，保持"我在变强、世界更难"的动态平衡。
4. **边界不蔓延**：MVP 封顶 3 区域 / 2 伙伴 / 2 危机级 / 4 次奖励，不做开放世界。
